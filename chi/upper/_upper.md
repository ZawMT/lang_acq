# Chinese Upper

Here are the topics to cover upper-level Chinese (Mandarin): idioms, set phrases and colloquial expressions.

**Writing convention:** examples use traditional characters (as in Taiwan), followed by Zhuyin and Pinyin: 你好 ㄋㄧˇ ㄏㄠˇ *nǐ hǎo*. English translations use normal brackets: (hello).

## Chengyu (成語)

Four-character set phrases, mostly from classical texts.
