# Adjectives (形容詞)

Chinese adjectives **work like verbs**: they can be the whole predicate, with no 是 (be).

> 她很高。 → *Tā hěn gāo.* (She's tall.)
> 今天很冷。 → *Jīntiān hěn lěng.* (It's cold today.)

They take the same tools as verbs:

| | Example |
|---|---|
| negation | 不高 (not tall) |
| question | 高不高？ / 高嗎？ (Is it tall?) |
| change with 了 | 天黑了。 (It's got dark.) |

## The "empty" 很

In a plain statement, an adjective almost always takes **很** ㄏㄣˇ *hěn*. Here 很 is usually **unstressed** and doesn't really mean "very"; it just completes the sentence.

> 我很忙。 → *Wǒ hěn máng.* (I'm busy.)

Without 很, a bare adjective sounds like a **contrast** or comparison:

> 她高，我矮。 → (She's tall, but I'm short.)
> 這個貴。 → (This one's the expensive one.)

**No 很** in questions and negatives:

> 你忙嗎？ (Are you busy?) / 我不忙。 (I'm not busy.)

For a real "very", stress 很, or use a stronger word (below).

## Degree words

| Word | Zhuyin | Pinyin | Meaning | Example |
|---|---|---|---|---|
| **有點(兒)** | ㄧㄡˇ ㄉㄧㄢˇ | yǒudiǎn | a bit (usually negative) | 有點貴 (a bit pricey) |
| **比較** | ㄅㄧˇ ㄐㄧㄠˋ | bǐjiào | rather, relatively | 比較好 (better) |
| **很** | ㄏㄣˇ | hěn | (neutral) / very | 很好 |
| **真** | ㄓㄣ | zhēn | really | 真好吃！ (Really tasty!) |
| **好** | ㄏㄠˇ | hǎo | so (spoken, Taiwan) | 好可愛！ (So cute!) |
| **非常** | ㄈㄟ ㄔㄤˊ | fēicháng | extremely | 非常重要 (extremely important) |
| **太…了** | ㄊㄞˋ…˙ㄌㄜ | tài… le | too; so (exclamation) | 太貴了！ (Too expensive!) / 太好了！ (Great!) |
| **…極了** | ㄐㄧˊ ˙ㄌㄜ | jí le | extremely (after) | 好極了 (excellent) |
| **最** | ㄗㄨㄟˋ | zuì | most | 最好 (best) |

### 有點 vs 一點

| | Position | Feel | Example |
|---|---|---|---|
| **有點** | **before** the adjective | a bit too…, complaint | 這個**有點**貴。 (This is a bit expensive.) |
| **一點** | **after** the adjective | a bit more… (compared, request) | 可以便宜**一點**嗎？ (Could it be a bit cheaper?) |

**Trap:** 有點好 ✗ sounds odd, since 有點 is for unwelcome qualities.

## Adjectives before nouns

| Adjective | Pattern | Example |
|---|---|---|
| one syllable | directly | **好**人 (good person), **新**書 (new book), **大**房子 (big house) |
| two syllables | + 的 | **漂亮的**花 (beautiful flower), **乾淨的**房間 (clean room) |
| with an adverb | + 的 | **很大的**房子 (a very big house) |

Some common two-syllable pairs go without 的 when they form a set phrase: 聰明人 (clever person), 重要問題 (important issue).

## Reduplication: vivid description

Doubling an adjective makes it **vivid**, like painting a picture. Then **no 很**:

| Pattern | Example |
|---|---|
| AA(的) | 高高的 (nice and tall), 紅紅的臉 (a rosy face) |
| AABB | 乾乾淨淨 (spotless), 高高興興 (happily), 清清楚楚 (crystal clear) |

> 房間打掃得**乾乾淨淨**的。 (The room was cleaned spotless.)

See [Reduplication](./22_reduplication.md).

## Adjective + 了: change

> 天黑了。 (It's got dark.)
> 他胖了。 (He's put on weight.)
> 衣服小了。 (The clothes have got too small.)

## Adjectives as adverbs

Add **地** (*de*) to describe how something is done: 高興**地**說 (say happily). Or use a complement with **得**: 說**得**很清楚 (say it clearly). See [的, 地, 得](./13_de_de_de.md).
