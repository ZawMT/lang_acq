# Greetings (問候語)

## Hello

| Expression | Zhuyin | Pinyin | Use |
|---|---|---|---|
| **你好** | ㄋㄧˇ ㄏㄠˇ | nǐ hǎo | hello (neutral; a bit formal between friends) |
| **您好** | ㄋㄧㄣˊ ㄏㄠˇ | nín hǎo | hello (polite) |
| **大家好** | ㄉㄚˋ ㄐㄧㄚ ㄏㄠˇ | dàjiā hǎo | hello, everyone |
| **嗨** | ㄏㄞ | hāi | hi (casual) |
| **早安** / **早** | ㄗㄠˇ ㄢ | zǎo'ān / zǎo | good morning (Taiwan) |
| **早上好** | ㄗㄠˇ ˙ㄕㄤ ㄏㄠˇ | zǎoshang hǎo | good morning (mainland) |
| **午安** | ㄨˇ ㄢ | wǔ'ān | good afternoon (Taiwan, a bit formal) |
| **晚安** | ㄨㄢˇ ㄢ | wǎn'ān | **good night** (before bed) |

**Trap:** **晚安** means "good night" when parting or going to bed, not "good evening". For "good evening", use 晚上好 (mainland) or just 你好.

## Casual greetings

Friends often skip 你好 and greet with a question about what you're doing:

| Expression | Pinyin | Meaning |
|---|---|---|
| **吃飽了嗎？ / 吃飯了嗎？** | chī bǎo le ma? / chī fàn le ma? | Have you eaten? |
| **去哪裡啊？** | qù nǎlǐ a? | Where are you off to? |
| **最近怎麼樣？** | zuìjìn zěnmeyàng? | How have you been? |
| **最近好嗎？** | zuìjìn hǎo ma? | How are you doing? |
| **好久不見！** | hǎojiǔ bú jiàn! | Long time no see! |

**吃飽了嗎?** is a traditional greeting, especially among older people. It's not an invitation: reply **吃了，你呢？** (Yes, and you?).

## Goodbye

| Expression | Pinyin | Use |
|---|---|---|
| **再見** | zàijiàn | goodbye |
| **掰掰** | bāibāi | bye-bye (very common, casual) |
| **明天見** | míngtiān jiàn | see you tomorrow |
| **待會見** | dāihuǐ jiàn | see you later (today) |
| **下次見** | xiàcì jiàn | see you next time |
| **慢走** | màn zǒu | take care (host to a departing guest; lit. walk slowly) |
| **保重** | bǎozhòng | take care (longer parting) |
| **路上小心** | lùshàng xiǎoxīn | have a safe trip |

## Thanks and apologies

| Expression | Pinyin | Meaning |
|---|---|---|
| **謝謝** | xièxie | thank you |
| **謝謝你 / 謝謝您** | xièxie nǐ / nín | thank you (warmer / polite) |
| **多謝** | duōxiè | many thanks |
| **不客氣** | bú kèqì | you're welcome |
| **不會** | bú huì | no problem (Taiwan; lit. it won't [be trouble]) |
| **不用謝** | bú yòng xiè | no need to thank me |
| **對不起** | duìbuqǐ | I'm sorry |
| **不好意思** | bù hǎoyìsi | sorry, excuse me (lighter) |
| **沒關係** | méi guānxi | it's fine, never mind |
| **沒事** | méi shì | it's nothing, no worries |

## Meeting someone

| Expression | Pinyin | Meaning |
|---|---|---|
| **你叫什麼名字？** | nǐ jiào shénme míngzi? | What's your name? |
| **您貴姓？** | nín guìxìng? | May I ask your surname? (polite) |
| **我叫…** / **我是…** | wǒ jiào… / wǒ shì… | I'm called… / I'm… |
| **我姓…** | wǒ xìng… | My surname is… |
| **很高興認識你** | hěn gāoxìng rènshi nǐ | Nice to meet you |
| **請多指教** | qǐng duō zhǐjiào | Please guide me (polite phrase on meeting) |
| **幸會** | xìnghuì | Pleased to meet you (formal) |

## In shops and restaurants

| Expression | Pinyin | Who says it |
|---|---|---|
| **歡迎光臨** | huānyíng guānglín | staff: Welcome! (on entering) |
| **幾位？** | jǐ wèi? | staff: How many people? |
| **老闆，…** | lǎobǎn, … | customer: calling the owner (at stalls, small shops) |
| **買單 / 結帳** | mǎidān / jiézhàng | customer: the bill, please |
| **謝謝光臨** | xièxie guānglín | staff: Thank you for coming |
