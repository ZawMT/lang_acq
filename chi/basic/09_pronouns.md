# Pronouns (代詞)

## Personal pronouns

| | Singular | Plural |
|---|---|---|
| 1st | **我** ㄨㄛˇ *wǒ* (I, me) | **我們** *wǒmen* (we, us) / **咱們** *zánmen* (we, inclusive) |
| 2nd | **你** ㄋㄧˇ *nǐ* (you) / **您** ㄋㄧㄣˊ *nín* (polite) | **你們** *nǐmen* |
| 3rd | **他** ㄊㄚ *tā* (he) / **她** *tā* (she) / **它** *tā* (it) | **他們** / **她們** / **它們** *tāmen* |

- **No case**: 我 is both "I" and "me": 我愛你, 你愛我.
- **們** ˙ㄇㄣ *men* makes the plural.
- **他, 她, 它 all sound the same**: *tā*. The difference is only in writing. A mixed group is **他們**.
- **咱們** (northern speech) includes the listener: "you and I". 我們 can include or exclude them.
- **您** is polite. Its plural is normally **各位** (everyone) or **你們**; 您們 is rare. See [Politeness](./23_politeness.md).

### Taiwan writing variants

| Character | Use |
|---|---|
| **妳** | "you" for a woman (Taiwan) |
| **牠** | "it" for animals |
| **祂** | "he" for God or gods |

All are pronounced like the basic forms (妳 *nǐ*, 牠 / 祂 *tā*).

## Possession: 的

Add **的** *de* for "my, your, his…":

| | Example |
|---|---|
| 我的 | 我的書 (my book) |
| 你的 | 你的手機 (your phone) |
| 他們的 | 他們的家 (their home) |

**Drop 的** with close relationships and groups you belong to:

> 我媽媽 (my mum), 我朋友 (my friend), 我家 (my home), 我們公司 (our company)

**的 alone** = "mine, yours": 這是**我的**。 (This is mine.)

## Demonstratives: 這, 那, 哪

| | This | That | Which? |
|---|---|---|---|
| basic | **這** ㄓㄜˋ *zhè* | **那** ㄋㄚˋ *nà* | **哪** ㄋㄚˇ *nǎ* |
| + measure word | 這個, 這本 | 那個, 那本 | 哪個, 哪本 |
| plural | 這些 (these) | 那些 (those) | 哪些 (which ones) |
| place | 這裡 / 這兒 (here) | 那裡 / 那兒 (there) | 哪裡 / 哪兒 (where) |

- Before a measure word, many speakers say **zhèi, nèi, něi**: 這個 *zhèige*, 那個 *nèige*.
- 這裡/那裡/哪裡 are more common in Taiwan; 這兒/那兒/哪兒 in Beijing.
- **那** (*nà*, that) and **哪** (*nǎ*, which) differ only in tone and the 口 radical: watch the tone.

> 這是什麼？ (What's this?)
> 那個人是誰？ (Who's that person?)
> 你住在哪裡？ (Where do you live?)

## Question pronouns

| Word | Zhuyin | Pinyin | Meaning |
|---|---|---|---|
| **誰** | ㄕㄟˊ | shéi / shuí | who |
| **什麼** | ㄕㄣˊ ˙ㄇㄜ | shénme | what |
| **哪** + measure | ㄋㄚˇ | nǎ | which |
| **哪裡** | ㄋㄚˇ ㄌㄧˇ | nǎlǐ | where |
| **怎麼** | ㄗㄣˇ ˙ㄇㄜ | zěnme | how |
| **為什麼** | ㄨㄟˋ ㄕㄣˊ ˙ㄇㄜ | wèishénme | why |
| **幾 / 多少** | ㄐㄧˇ / ㄉㄨㄛ ㄕㄠˇ | jǐ / duōshǎo | how many |

They stay **in place** in the sentence. See [Questions](./10_questions.md).

## Dropping pronouns

Pronouns are **dropped** when they're clear from context:

> A: (你)去哪裡？ B: (我)去學校。 → (Where are you going? — To school.)

Using 你 too often, especially to a superior, can sound blunt. Titles are often used instead of "you": 老師，您要喝茶嗎？ (Teacher, would you like some tea?)
