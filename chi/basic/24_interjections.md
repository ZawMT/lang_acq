# Interjections (嘆詞)

**Interjections** (嘆詞 ㄊㄢˋ ㄘˊ *tàncí*, in Taiwan often 感嘆詞) stand on their own and express a reaction. Their **tone** often changes with the feeling, so written tones are only a guide.

## Emotion

| Word | Pinyin | Feeling | Example |
|---|---|---|---|
| **啊** | a (any tone) | surprise, realization | **啊**，我忘了！ (Ah, I forgot!) |
| **啊？** | á (rising) | what?, huh? | **啊**？你說什麼？ (Huh? What did you say?) |
| **哇** | wa | wow | **哇**，好漂亮！ (Wow, so beautiful!) |
| **哎呀** | āiyā | oops, oh dear | **哎呀**，下雨了！ (Oh no, it's raining!) |
| **哎喲** | āiyō | ouch; oh my | **哎喲**，好痛！ (Ouch, that hurts!) |
| **唉** | ài | sigh | **唉**，真累。 (Sigh, I'm so tired.) |
| **咦** | yí | puzzled | **咦**？我的錢包呢？ (Huh? Where's my wallet?) |
| **哦 / 喔** | ò / ō | oh, I see | **哦**，原來如此。 (Oh, I see.) |
| **哼** | hng | humph (annoyed) | **哼**，我不理你了！ (Humph, I'm not talking to you!) |
| **噓** | xū | shh | **噓**，小聲點！ (Shh, keep it down!) |
| **天啊 / 我的天** | tiān a / wǒ de tiān | oh my god | **天啊**！真的嗎？ (Oh my god! Really?) |

## Getting attention

| Word | Pinyin | Use |
|---|---|---|
| **喂** | wéi / wèi | hello (on the phone); hey! |
| **欸** | ê / èi | hey (casual) |
| **嘿** | hēi | hey (friendly) |
| **請問** | qǐngwèn | excuse me (to a stranger) |
| **不好意思** | bù hǎoyìsi | excuse me (polite; very common in Taiwan) |
| **老闆** | lǎobǎn | (calling a shop or stall owner) |

On the phone: **喂**，你好！ (Hello?)

**Trap:** 喂 to a person face to face can sound **rude**. Use 不好意思 or 請問 with strangers.

## Agreeing and answering

Chinese has no single "yes" or "no" (see [Questions](./10_questions.md#answering-yes-and-no)), but these short replies are everywhere:

| Word | Pinyin | Meaning |
|---|---|---|
| **嗯** | ng / en | mm, yeah |
| **對** / **對對對** | duì | right, yes (that's correct) |
| **是** | shì | yes (formal; to 是 questions) |
| **好** | hǎo | OK |
| **沒錯** | méi cuò | exactly |
| **不是** | bú shì | no, that's not it |
| **沒有** | méiyǒu | no (didn't / don't have) |
| **不會** | bú huì | no problem (Taiwan reply to thanks) |

## Listening responses

When someone is talking, Chinese listeners give short responses to show they're following:

| Response | Feel |
|---|---|
| **嗯 / 嗯嗯** | mm-hm |
| **對啊** | yeah, right |
| **是喔？** | oh really? (Taiwan) |
| **真的嗎？** | really? |
| **然後呢？** | and then? |
| **好厲害！** | amazing! |
| **原來如此** | I see, so that's it |

## Fillers

Fillers buy you time to think:

| Filler | Pinyin | Use |
|---|---|---|
| **嗯…** | ng | um |
| **那個…** | nèige | er, that… (very common) |
| **這個…** | zhèige | um, this… |
| **就是…** | jiùshì | like, I mean |
| **然後…** | ránhòu | and then… (overused in Taiwan, almost like "and um") |
| **怎麼說呢…** | zěnme shuō ne | how should I put it… |
