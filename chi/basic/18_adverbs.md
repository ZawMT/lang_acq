# Adverbs (副詞)

Adverbs go **after the subject, before the verb** (or adjective):

> 我**也**去。 (I'm going too.) 也我去 ✗
> 他們**都**是學生。 (They're all students.)

Only a few, like 其實 (actually), 突然 (suddenly), 也許 (maybe), can also go before the subject.

Chinese uses many **short adverbs** where English uses longer phrases or tenses. 就, 才, 還, 都 alone can change the whole feel of a sentence.

## The key small adverbs

| Word | Zhuyin | Pinyin | Main meanings |
|---|---|---|---|
| **都** | ㄉㄡ | dōu | all, both; even |
| **也** | ㄧㄝˇ | yě | also, too; (not) either |
| **還** | ㄏㄞˊ | hái | still; also, in addition; fairly |
| **再** | ㄗㄞˋ | zài | again (future); then |
| **又** | ㄧㄡˋ | yòu | again (past) |
| **就** | ㄐㄧㄡˋ | jiù | right away, as early as; only; then |
| **才** | ㄘㄞˊ | cái | only then, as late as; only |
| **只** | ㄓˇ | zhǐ | only |
| **已經** | ㄧˇ ㄐㄧㄥ | yǐjīng | already |

## 都: all

都 refers **back** to a plural that comes **before** it:

> 我們**都**喜歡吃辣。 → (We all like spicy food.)
> 這些書我**都**看過。 → (I've read all these books.)

- 每…都: 我**每天都**運動。 (I exercise every day.)
- Question word + 都 = every…: **誰都**知道。 (Everyone knows.) **什麼都**吃。 (I eat anything.)
- 都 can't refer forward: 我都看過這些書 ✗.

## 也: also

> 我**也**是學生。 (I'm a student too.)
> 他不去，我**也**不去。 (He's not going, and I'm not either.)

With 都: **也** comes first: 我們**也都**去。 (We're all going too.)

## 再 vs 又: again

| | Time | Example |
|---|---|---|
| **再** | **future** again (not yet happened) | 請**再**說一次。 (Please say it again.) / 明天**再**來。 (Come again tomorrow.) |
| **又** | **past** again (already happened) | 他昨天**又**遲到了。 (He was late again yesterday.) |

> 我**再**想想。 (Let me think it over.)
> 先吃飯，**再**做作業。 (Eat first, then do your homework.)

## 就 vs 才: early vs late, easy vs hard

| | Feel | Example |
|---|---|---|
| **就** | early, quick, easy | 他八點**就**來了。 (He came at eight already — early.) |
| **才** | late, slow, difficult | 他十點**才**來。 (He didn't come till ten — late.) |

> 我一看**就**懂了。 (I understood as soon as I saw it.)
> 我看了三遍**才**懂。 (I only understood after reading it three times.)

With 才, the sentence usually has **no 了**.

就 also means "**exactly**, **just**": 他**就**是我哥哥。 (He's my brother — that's him.) 就 in "if… then" sentences: see [Connecting Clauses](./20_connecting_clauses.md).

才 also means "**only**" with numbers: 他**才**五歲。 (He's only five.)

## 還: still, also

| Meaning | Example |
|---|---|
| still | 他**還**在睡覺。 (He's still sleeping.) |
| not yet (還沒) | 我**還沒**吃。 (I haven't eaten yet.) |
| also, in addition | 我買了蘋果，**還**買了香蕉。 (I bought apples, and bananas too.) |
| even more (comparison) | 他比我**還**高。 (He's even taller than me.) |
| fairly, OK | **還**好。 (Not bad / it's OK.) |

## Order of several adverbs

When several come together, a common order is:

> time / attitude → 也 → 都 → 不 → others → verb

> 我們**明天也都不**去了。 (We're none of us going tomorrow either.)
