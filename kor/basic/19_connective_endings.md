# Connective Endings (연결 어미)

Inside one sentence, Korean joins clauses with **connective endings** attached to the first clause's predicate. The ending itself says how the two clauses relate: "and", "but", "because", "if", "while"...

- 비가 와**서** 집에 있었어요. (It rained, so I stayed home.)
- 비가 오**지만** 나갈 거예요. (It's raining, but I'll go out.)
- 비가 오**면** 집에 있을 거예요. (If it rains, I'll stay home.)

The **final** clause carries the speech level and sentence type; the connected clause doesn't (see [Verb endings](./06_verb_endings.md)). To connect two separate sentences, use a conjunctive adverb instead (그리고, 그래서... see [Adverbs](./12_adverbs.md)).

## Overview

| Meaning | Ending | Example |
|---|---|---|
| and, and then | -고 | 먹**고** 자요. |
| so, because | -아/어서 | 피곤해**서** 자요. |
| because (reason + command OK) | -(으)니까 | 늦었**으니까** 빨리 가자. |
| but | -지만 | 작**지만** 편해요. |
| background, but | -(으)ㄴ/는데 | 배고픈**데** 뭐 먹을까요? |
| if, when | -(으)면 | 시간 있**으면** 와요. |
| even if, even though | -아/어도 | 비가 와**도** 가요. |
| while (simultaneous) | -(으)면서 | 걸으**면서** 이야기해요. |
| (in order) to go/come | -(으)러 | 밥 먹**으러** 가요. |
| in order to, intending to | -(으)려고 | 사**려고** 왔어요. |
| or | -거나 | 책을 읽**거나** 쉬어요. |
| while doing, and then (switch) | -다가 | 가**다가** 돌아왔어요. |

## Listing and sequence

### -고: "and", "and then"

Joins two facts, or two actions in order:

- 이 식당은 싸**고** 맛있어요. (This restaurant is cheap and tasty.)
- 숙제를 하**고** 잤어요. (I did my homework and then slept.)

Past can be marked on the first clause or left to the last: 어제 영화를 보**고** 밥을 먹었어요 (Yesterday I watched a movie and ate).

**-고 나서** stresses "after finishing": 밥을 먹**고 나서** 커피를 마셔요. (After eating, I have coffee.)

### -아/어서 (sequence): "and then (there / with it)"

When the first action **sets up** the second (same place, same object, or the way you do it), use -아/어서 instead of -고:

| -아/어서 (linked) | -고 (just sequence) |
|---|---|
| 친구를 만나**서** 영화를 봤어요. (I met a friend and watched a movie **with them**.) | 친구를 만나**고** 영화를 봤어요. (I met a friend, then watched a movie.) (maybe alone) |
| 의자에 앉**아서** 기다리세요. (Sit on the chair and wait.) | |
| 사과를 씻**어서** 먹었어요. (I washed the apple and ate it.) | |

## Reason and cause

| | -아/어서 | -(으)니까 | -기 때문에 |
|---|---|---|---|
| Feel | neutral, natural cause | the speaker's reason, "since" | formal, emphatic |
| Past on the first clause | ✗ (갔어서) | ✓ (갔으니까) | ✓ (갔기 때문에) |
| Command / "let's" after it | ✗ | ✓ | ✗ |
| Polite excuses, thanks, apologies | ✓ (늦어서 죄송해요) | ✗ (sounds like blaming) | ✓ |

- 배가 고파**서** 라면을 먹었어요. (I was hungry, so I ate ramyeon.)
- 늦었**으니까** 택시를 타세요. (It's late, so take a taxi.)
- 시간이 없**기 때문에** 못 가요. (Because I don't have time, I can't go.)

**Trap:** -아/어서 can't be followed by a command or suggestion: ✗ 비가 와서 우산을 가져가세요. ✓ 비가 오**니까** 우산을 가져가세요 (It's raining, so take an umbrella).

**Trap:** -아/어서 doesn't take the past marker: ✗ 어제 늦었어서. ✓ 어제 늦**어서** 죄송해요 (Sorry I was late yesterday). The tense comes from the final clause.

For nouns: **N 때문에** (because of N) or **N(이)라서** (because it's N): 비 **때문에** (because of the rain), 주말**이라서** 사람이 많아요 (It's the weekend, so it's crowded).

### -(으)니까: discovery

With a past action, -(으)니까 also means "when I did X, I found that...":

- 집에 가**니까** 아무도 없었어요. (When I got home, there was nobody there.)

## Contrast

### -지만: "but"

A clear contrast:

- 한국어는 어렵**지만** 재미있어요. (Korean is difficult but fun.)
- 가고 싶었**지만** 못 갔어요. (I wanted to go, but I couldn't.)

### -(으)ㄴ/는데: background, soft contrast

Very common and flexible. It sets up **background** for what follows, or a mild contrast:

| Stem | Form |
|---|---|
| verbs, 있다/없다 | **-는데**: 가는데, 먹는데, 맛있는데 |
| adjectives | **-(으)ㄴ데**: 큰데, 작은데 |
| 이다 | **인데**: 학생인데 |
| past (any) | **-았/었는데**: 갔는데, 컸는데 |

- 지금 밥 먹**는데** 같이 먹을래요? (I'm eating now; want to join me?)
- 이 옷 예쁜**데** 좀 비싸요. (These clothes are pretty, but a bit expensive.)
- 어제 전화했**는데** 안 받았어요. (I called yesterday, but you didn't answer.)

At the end of a sentence, -는데요 softens the statement and invites a reply (see [Verb endings](./06_verb_endings.md)).

### -아/어도: "even if", "even though"

- 비가 와**도** 갈 거예요. (Even if it rains, I'll go.)
- 아무리 먹어**도** 배가 고파요. (No matter how much I eat, I'm hungry.)

## Condition

| Ending | Meaning | Example |
|---|---|---|
| **-(으)면** | if, when (real condition) | 시간이 있**으면** 연락하세요. (If you have time, get in touch.) |
| **-(ㄴ/는)다면** | if (hypothetical, less likely) | 복권에 당첨**된다면** 뭐 할 거예요? (If you won the lottery, what would you do?) |
| **-았/었더라면** | if ... had (counterfactual past) | 일찍 출발**했더라면** 안 늦었을 거예요. (If I had left early, I wouldn't have been late.) |
| **-거든** | if (followed by a command/suggestion) | 도착하**거든** 전화하세요. (Call me when you arrive.) |

-(으)면 also covers "whenever": 봄이 되**면** 꽃이 펴요. (When spring comes, flowers bloom.)

## Purpose

| Ending | Use | Example |
|---|---|---|
| **-(으)러** | only with **가다, 오다, 다니다** | 밥 먹**으러** 가요. (I'm going to eat.) |
| **-(으)려고** | "intending to", with most verbs | 선물을 사**려고** 돈을 모았어요. (I saved money to buy a present.) |
| **-기 위해(서)** | "in order to" (formal) | 건강을 지키**기 위해서** 운동해요. (I exercise to stay healthy.) |

**Trap:** -(으)러 only works when the main verb is 가다, 오다, or 다니다: 사**러** 가요 ✓ (I'm going to buy it), but ✗ 사러 돈을 모았어요. Use -(으)려고 there.

## Time

| Ending | Meaning | Example |
|---|---|---|
| **-(으)면서** | while (same subject, both at once) | 음악을 들으**면서** 공부해요. (I study while listening to music.) |
| **-다가** | was doing ..., then switched / interrupted | 공부하**다가** 잠들었어요. (I fell asleep while studying.) |
| **-자마자** | as soon as | 집에 오**자마자** 잤어요. (As soon as I got home, I slept.) |
| **-고 나서** | after finishing | |
| **-기 전에 / -(으)ㄴ 후에** | before / after | See [Modifier clauses](./20_modifier_clauses.md) |

**Trap:** -(으)면서 and -다가 need the **same subject** in both clauses.

## Choice: -거나

- 주말에는 영화를 보**거나** 친구를 만나요. (On weekends I watch movies or meet friends.)

For nouns, use **(이)나**: 커피**나** 차 (coffee or tea).

## Degree

| Ending | Meaning | Example |
|---|---|---|
| **-(으)ㄹ수록** | the more ..., the more | 보**면 볼수록** 좋아요. (The more I see it, the more I like it.) |
| **-도록** | so that, until | 늦지 않**도록** 일찍 출발하세요. (Leave early so you won't be late.) |
| **-게** | so that | 잘 들리**게** 크게 말해 주세요. (Speak loudly so I can hear.) |
