# Adverbs (부사)

An adverb modifies a verb, an adjective, another adverb, or a whole sentence. Korean adverbs **never change form**, and they usually sit **right before** what they modify.

- **빨리** 오세요. (Come quickly.)
- **아주** 맛있어요. (It's very tasty.)

## Making adverbs

| Ending | Added to | Examples |
|---|---|---|
| **-게** | almost any adjective (productive) | 크다 → 크**게**, 쉽다 → 쉽**게**, 예쁘다 → 예쁘**게** |
| **-이** | some adjectives (fixed list) | 많다 → 많**이**, 같다 → 같**이**, 깨끗하다 → 깨끗**이**, 높다 → 높**이** |
| **-히** | many 하다 adjectives (fixed list) | 조용하다 → 조용**히**, 솔직하다 → 솔직**히**, 특별하다 → 특별**히**, 편안하다 → 편안**히** |

- 쉽**게** 설명해 주세요. (Please explain it simply.)
- 많**이** 드세요. (Please eat a lot. / Enjoy your meal.)
- **열심히** 공부해요. (I study hard.)

Some everyday -히 adverbs have no adjective behind them: **천천히** (slowly), **열심히** (hard, diligently).

Many 하다 adjectives accept both **-히** and **-게**: 조용히 / 조용하게 (quietly). -히 feels more like a fixed word; -게 more descriptive.

**Trap:** 빠르다 (fast) → 빠르게 exists, but the everyday word for "quickly" is **빨리**. Likewise 늦다 (late) → **늦게** (late).

## Common adverbs by type

### Degree

| Adverb | Meaning | Example |
|---|---|---|
| **아주 / 매우** | very (매우 is written) | 아주 좋아요. (It's very good.) |
| **정말 / 진짜** | really (진짜 is casual) | 정말 고마워요. (Thank you so much.) |
| **너무** | too; (in speech) very | 너무 비싸요. (It's too expensive.) / 너무 좋아요! (I love it!) |
| **꽤** | quite, fairly | 꽤 어려워요. (It's quite hard.) |
| **좀 / 조금** | a little | 좀 추워요. (It's a bit cold.) |
| **더 / 덜** | more / less | 더 주세요. (Give me more, please.) |
| **제일 / 가장** | most | 제일 좋아요. (It's the best.) |
| **거의** | almost | 거의 다 왔어요. (We're almost there.) |

**좀** is also a softener in requests, with no real meaning of "a little": 이거 **좀** 도와주세요. (Could you help me with this?)

### Time

| Adverb | Meaning | Adverb | Meaning |
|---|---|---|---|
| **지금** | now | **아까** | a while ago (today) |
| **이따가** | later (today) | **나중에** | later (some time) |
| **벌써** | already (sooner than expected) | **이미** | already (done) |
| **아직** | still; (with a negative) not yet | **곧** | soon |
| **먼저** | first, ahead | **다시** | again |
| **방금** | just now | **드디어** | finally |

- **아직** 안 먹었어요. (I haven't eaten yet.)
- **벌써** 다 먹었어요? (You've already eaten it all?)

### Frequency

| Adverb | Meaning |
|---|---|
| **항상 / 늘 / 언제나** | always |
| **보통** | usually |
| **자주** | often |
| **가끔** | sometimes |
| **별로** (+ negative) | not really, not much |
| **거의** (+ negative) | hardly ever |
| **전혀** (+ negative) | not at all |

- 저는 **가끔** 커피를 마셔요. (I sometimes drink coffee.)
- 커피를 **별로** 안 좋아해요. (I don't really like coffee.)

### Manner

| Adverb | Meaning |
|---|---|
| **빨리** | quickly |
| **천천히** | slowly |
| **잘** | well |
| **같이 / 함께** | together |
| **혼자** | alone |
| **열심히** | diligently, hard |
| **다** | all, completely |

## Negative-only adverbs

Some adverbs **must** be followed by a negative (안, 못, 없다, 모르다...):

| Adverb | Meaning | Example |
|---|---|---|
| **별로** | not particularly | 별로 안 비싸요. (It's not that expensive.) |
| **전혀** | not at all | 전혀 몰라요. (I have no idea.) |
| **절대(로)** | never, absolutely not | 절대 안 가요. (I'll never go.) |
| **하나도** | not even one, not at all | 하나도 안 매워요. (It's not spicy at all.) |
| **아무도 / 아무것도** | nobody / nothing | 아무도 없어요. (Nobody's here.) |

✗ 별로 좋아요. ✓ 별로 **안** 좋아요. See [Negation](./16_negation.md).

## Placement

Adverbs normally go directly before the word they modify:

- 한국어를 **잘** 해요. (I speak Korean well.)
- **아주** 빨리 걸어요. (He walks very fast.)

Time adverbs usually come early in the sentence: 저는 **내일** 부산에 가요. (I'm going to Busan tomorrow.)

**Trap:** with 하다 verbs made from a noun, the negation adverbs **안 / 못** go between the noun and 하다: 공부 **안** 해요 (I don't study), not 안 공부해요. The same happens with **잘 못**: 운전 **잘 못**해요 (I'm not a good driver).

**Trap:** spacing changes meaning with 잘 and 못:

| | Meaning |
|---|---|
| 잘 **못** 해요 | I'm not good at it |
| **잘못**했어요 | I did something wrong / I'm sorry |

## Sentence adverbs and connectors

These modify or link whole sentences. They're how Korean joins two separate sentences (inside one sentence, [connective endings](./19_connective_endings.md) do the job).

| Adverb | Meaning | Example |
|---|---|---|
| **그리고** | and (then) | 밥을 먹었어요. **그리고** 커피를 마셨어요. (I ate. And then I had coffee.) |
| **그래서** | so, therefore | 비가 와요. **그래서** 집에 있어요. (It's raining. So I'm staying home.) |
| **그런데 (근데)** | but, by the way | 좋아요. **그런데** 비싸요. (It's nice. But it's expensive.) |
| **하지만 / 그러나** | but, however (그러나 is written) | |
| **그러니까** | so (so I'm telling you) | |
| **그러면 (그럼)** | then, in that case | **그럼** 내일 만나요. (Then let's meet tomorrow.) |
| **그래도** | even so, still | |
| **아마** | probably | **아마** 비가 올 거예요. (It'll probably rain.) |
| **혹시** | by any chance | **혹시** 한국 사람이에요? (Are you Korean, by any chance?) |
| **사실** | actually, in fact | |

**혹시** is used a lot to soften questions, especially to strangers.

## Sound and shape words (의성어 / 의태어)

Korean has a huge set of adverbs that imitate **sounds** (의성어) or **shapes and movements** (의태어), usually by repetition. They're very common in speech and writing.

| Word | Type | Meaning | Example |
|---|---|---|---|
| **멍멍** | sound | woof | 개가 멍멍 짖어요. (The dog barks.) |
| **야옹** | sound | meow | |
| **쿨쿨** | sound | snoring, sound asleep | 쿨쿨 자요. (He's fast asleep.) |
| **똑똑** | sound | knock knock | |
| **반짝반짝** | shape | twinkling, sparkling | 별이 반짝반짝 빛나요. (The stars twinkle.) |
| **두근두근** | shape | heart pounding | 가슴이 두근두근해요. (My heart is pounding.) |
| **엉금엉금** | shape | crawling slowly | |
| **깜짝** | shape | with a start | 깜짝 놀랐어요. (I was startled.) |
| **꼭** | shape | tightly; for sure | 꼭 오세요! (Be sure to come!) |

Many combine with **-하다** or **-거리다** to become verbs: 두근두근하다, 반짝거리다.
