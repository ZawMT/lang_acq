# Verb Endings (어미)

Korean predicates (동사, 형용사, and 이다) are built from a **stem** plus one or more **endings**. The stem carries the meaning; the endings carry tense, politeness, sentence type, and how the clause links to the rest of the sentence.

## Stem (어간)

Take the dictionary form and remove **-다**:

| Dictionary form | Stem |
|---|---|
| 가다 (to go) | **가-** |
| 먹다 (to eat) | **먹-** |
| 공부하다 (to study) | **공부하-** |
| 예쁘다 (to be pretty) | **예쁘-** |
| 이다 (to be) | **이-** |

The dictionary form itself is never used in conversation. It's only a citation form (and the plain written style, see [Speech levels](./07_speech_levels.md)).

## Kinds of endings

| Kind | Where | Job | Examples |
|---|---|---|---|
| **선어말 어미** (pre-final endings) | between the stem and the final ending | honorific, tense, conjecture | -(으)시-, -았/었-, -겠- |
| **종결 어미** (final endings) | end of the sentence | speech level + sentence type | -아요/어요, -습니다, -(으)세요, -자 |
| **연결 어미** (connective endings) | end of a clause | link to the next clause | -고, -지만, -아서/어서, -(으)면 |
| **전성 어미** (transforming endings) | end of a clause | turn the clause into a modifier, noun, or adverb | -는, -(으)ㄴ, -기, -(으)ㅁ, -게 |

A predicate always ends with a final, connective, or transforming ending. Pre-final endings are optional.

## How endings attach: three shapes

Every ending belongs to one of three shapes, and the shape decides what happens at the join.

### 1. Direct: attaches to any stem as is

Endings starting with **ㄱ, ㄷ, ㅈ** (and a few others) just stick on:

| Ending | 가- | 먹- |
|---|---|---|
| -고 (and) | 가고 | 먹고 |
| -지만 (but) | 가지만 | 먹지만 |
| -네요 (oh, ...!) | 가네요 | 먹네요 |
| -기 (…ing) | 가기 | 먹기 |

### 2. -(으): 으 is added after a consonant

The **으** in brackets appears only when the stem ends in a consonant, to avoid two consonants clashing:

| Ending | 가- (vowel) | 읽- (consonant) |
|---|---|---|
| -(으)면 (if) | 가**면** | 읽**으면** |
| -(으)세요 (please) | 가**세요** | 읽**으세요** |
| -(으)ㄹ 거예요 (will) | 갈 거예요 | 읽**을** 거예요 |
| -(으)ㄴ (modifier, past) | 간 | 읽**은** |

**Trap:** stems ending in **ㄹ** act like vowel stems here (no 으): 살다 (to live) → 살**면**, not 살으면. See [Irregular verbs](./14_irregular_verbs.md).

### 3. -아/어: vowel harmony

Endings starting with 아/어 choose their vowel based on the **last vowel of the stem**:

| Stem's last vowel | Ending | Example |
|---|---|---|
| **ㅏ** or **ㅗ** | **-아** | 앉다 → 앉**아요**, 좋다 → 좋**아요** |
| anything else | **-어** | 먹다 → 먹**어요**, 읽다 → 읽**어요** |
| **하다** | **-여 → 해** | 하다 → **해요**, 공부하다 → 공부**해요** |

When the stem ends in a vowel, the two vowels usually **merge**:

| Stem | + 아/어 | Merged | 해요체 |
|---|---|---|---|
| 가- | 가 + 아 | 가 | **가요** |
| 서- (stand) | 서 + 어 | 서 | **서요** |
| 오- | 오 + 아 | 와 | **와요** |
| 보- | 보 + 아 | 봐 | **봐요** |
| 주- (give) | 주 + 어 | 줘 | **줘요** |
| 마시- (drink) | 마시 + 어 | 마셔 | **마셔요** |
| 보내- (send) | 보내 + 어 | 보내 | **보내요** |
| 되- (become) | 되 + 어 | 돼 | **돼요** |
| 쓰- (write) | 쓰 + 어 | 써 | **써요** (ㅡ drops) |

The same harmony applies to **every** 아/어-ending: -아요/어요, past -았/었-, -아서/어서, -아도/어도, -아야/어야, -아/어 주다...

- 가다 → 가**요**, 갔**어요**, 가**서**, 가**도**
- 먹다 → 먹**어요**, 먹**었어요**, 먹**어서**, 먹**어도**

### 이다

이다 is the particle "to be", and it has its own shapes:

| | After a consonant | After a vowel |
|---|---|---|
| 해요체 | 학생**이에요** | 의사**예요** |
| 합쇼체 | 학생**입니다** | 의사**입니다** |
| Past | 학생**이었어요** | 의사**였어요** |

Its negative is **아니다**: 학생이 **아니에요** (I'm not a student).

## Slot order

When several endings stack, they always come in this order:

```
stem  +  (으)시  +  았/었  +  겠  +  final ending
         honorific   past     conjecture/intention
```

| Pieces | Result | Meaning |
|---|---|---|
| 가 + 요 | **가요** | (I) go |
| 가 + 았 + 어요 | **갔어요** | (I) went |
| 가 + 시 + 어요 | **가세요** | (someone respected) goes / please go |
| 가 + 시 + 었 + 어요 | **가셨어요** | (someone respected) went |
| 가 + 시 + 었 + 겠 + 어요 | **가셨겠어요** | (someone respected) must have gone |
| 먹 + 었 + 지만 | **먹었지만** | (I) ate, but... |

-(으)시- + -어요 fuses into **-(으)세요**, and -(으)시- + -었- fuses into **-(으)셨-**.

## Final endings: speech level × sentence type

Every sentence ends with a final ending that shows **both** the speech level and the sentence type (statement, question, command, "let's"). Using 가다:

| | Statement | Question | Command | "Let's" |
|---|---|---|---|---|
| 합쇼체 (formal polite) | 갑니다 | 갑니까? | 가십시오 | 갑시다 |
| 해요체 (polite) | 가요 | 가요? | 가세요 | 가요 |
| 해체 (casual) | 가 | 가? | 가 | 가 |
| 해라체 (plain) | 간다 | 가니? / 가냐? | 가라 | 가자 |

The full picture is in [Speech levels](./07_speech_levels.md).

## Common endings at a glance

Sentence-final (with 요 for polite):

| Ending | Meaning | Example |
|---|---|---|
| -아요/어요 | plain statement / question | 먹어요. (I eat.) |
| -네요 | discovery, mild surprise | 맛있네요! (Oh, it's tasty!) |
| -군요 / -는군요 | realization | 한국 사람이군요. (So you're Korean.) |
| -지요 (-죠) | "right?", shared knowledge | 맛있죠? (It's tasty, right?) |
| -(으)ㄹ까요? | "shall we?", "I wonder" | 같이 갈까요? (Shall we go together?) |
| -(으)ㄹ게요 | promise, "I'll..." | 제가 할게요. (I'll do it.) |
| -(으)ㄹ래요 | "want to" (casual) | 뭐 먹을래요? (What do you want to eat?) |
| -거든요 | giving a reason the listener doesn't know | 오늘 바쁘거든요. (I'm busy today, you see.) |
| -는데요 | soft, leaves room for response | 지금 없는데요. (She's not here right now...) |

Connective endings are covered in [Connective endings](./19_connective_endings.md), and transforming endings in [Modifier clauses](./20_modifier_clauses.md).

## 요: the politeness add-on

Most casual (해체) endings become polite by simply adding **-요**:

| Casual | Polite |
|---|---|
| 가 | 가**요** |
| 맛있네 | 맛있네**요** |
| 그렇지 | 그렇지**요** → 그렇죠 |
| 할게 | 할게**요** |

The exception is 이다: casual **(이)야** → polite **이에요/예요** (학생이야 → 학생이에요).
