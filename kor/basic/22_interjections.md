# Interjections and Discourse Words (감탄사)

**감탄사** express feeling, call out to someone, or answer. They stand apart from the rest of the sentence and never change form. Korean conversation is also full of **fillers** and **back-channel responses** that keep the talk flowing.

## Emotion

| Word | Feeling | Example |
|---|---|---|
| **아** | realization, mild surprise | **아**, 그렇구나. (Ah, I see.) |
| **와 / 우와** | wonder, admiration | **우와**, 진짜 예쁘다! (Wow, it's so pretty!) |
| **어머 / 어머나** | surprise (used mostly by women) | **어머**, 정말요? (Oh my, really?) |
| **아이고** | ugh, oh dear; tiredness, pity, pain | **아이고**, 힘들어. (Oof, I'm exhausted.) |
| **어?** | huh? (something unexpected) | **어?** 내 지갑 어디 갔지? (Huh? Where did my wallet go?) |
| **앗** | oops, whoa (sudden) | **앗**, 뜨거워! (Ow, it's hot!) |
| **아야 / 아얏** | ouch | |
| **휴** | phew (relief) | **휴**, 다행이다. (Phew, what a relief.) |
| **에이** | come on, no way (doubt, disappointment) | **에이**, 설마. (Come on, no way.) |
| **헐** | whoa, OMG (slang, shock) | **헐**, 대박. (Whoa, amazing.) |
| **흥 / 칫** | hmph (sulking) | |
| **쉿** | shh | |

**대박** (literally "big success") works as an exclamation for anything amazing, good or bad: **대박!** (No way! / Awesome!).

## Answering

| Word | Level | Meaning |
|---|---|---|
| **네 / 예** | polite | yes; also "I see", "OK", "pardon?" (네?) |
| **아니요 / 아뇨** | polite | no |
| **응 / 어** | casual | yeah |
| **아니** | casual | no |
| **그럼(요)** | both | of course |
| **글쎄(요)** | both | well..., I'm not sure |

- **네?** (with rising tone) = "Sorry?" / "Pardon?"
- **네, 네.** = "Yes, yes / I'm listening."

Remember that 네 agrees with the **question**, so it can mean "no" in answer to a negative question (see [Sentence structure](./04_sentence_structure.md)).

## Calling out

| Word | Use |
|---|---|
| **여보세요** | hello (**phone** only) |
| **저기요** | excuse me (to get a stranger's attention) |
| **여기요** | excuse me! (calling staff in a restaurant) |
| **야** | hey (casual, to friends or younger people) |
| **얘** | hey (to a child) |
| name + **아/야** | calling someone casually: 민수**야**, 지민**아** |
| **여보** | honey (between spouses) |

**Trap:** **여보세요** is only for the phone (or someone who doesn't seem to hear you). To greet someone face to face, use 안녕하세요 (see [Basic salutations](./24_basic_salutations.md)).

## Fillers (hesitation)

Fillers give you time to think, like "um" or "well":

| Filler | Use |
|---|---|
| **음 / 어** | um, uh |
| **저 / 저기** | um, so... (before a request or awkward topic) |
| **그** | that... (searching for a word) |
| **뭐** | like, you know (casual) |
| **그러니까** | I mean, so... |
| **있잖아(요)** | you know what? (starting a topic) |
| **아니** | no, I mean... (correcting yourself, or starting a complaint) |
| **막** | like, just (casual, intensifying) |
| **좀** | a bit (softening) |

- **저기**, 혹시 시간 있으세요? (Um, excuse me, do you have a moment?)
- **있잖아**, 나 어제 민수 봤어. (You know what? I saw Minsu yesterday.)
- 그 사람 이름이 **그**... 뭐였지? (That person's name was... what was it?)

## Back-channel responses (맞장구)

Korean listeners respond **frequently** while the other person talks, to show they're following. Silence can sound like you're not listening.

| Response | Meaning |
|---|---|
| **네, 네 / 응, 응** | yes, yes (I'm listening) |
| **아~** | ah, I see |
| **그렇구나 / 그렇군요** | I see, so that's how it is |
| **진짜? / 정말요?** | really? |
| **맞아(요)** | right, exactly |
| **그러게(요)** | I know, right? |
| **그래(요)?** | is that so? |
| **어떡해** | oh no (sympathy) |
| **대박 / 헐** | wow (casual) |

- A: 어제 시험 봤는데 100점 받았어. (I took a test yesterday and got 100.)
- B: **진짜? 대박!** (Really? Amazing!)

## Texting

Written casual Korean uses consonant-only abbreviations:

| Text | Meaning |
|---|---|
| **ㅋㅋㅋ** | lol (from 크크) |
| **ㅎㅎ** | hehe (from 하하 / 흐흐; softer) |
| **ㅠㅠ / ㅜㅜ** | crying (tears running down) |
| **ㅇㅇ** | yeah (from 응응) |
| **ㄴㄴ** | no no (from 노노) |
| **ㄱㄱ** | let's go (from 고고) |
| **ㄱㅅ** | thanks (from 감사) |
| **ㅈㅅ** | sorry (from 죄송) |

These are for casual chats with friends only.

## Sound words

Imitative words like 멍멍 (woof) and 두근두근 (heart pounding) are adverbs in Korean grammar; see [Adverbs](./12_adverbs.md).
