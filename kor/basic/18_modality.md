# Modality (양태 표현)

Korean has no separate class of "modal verbs". Ability, obligation, permission, desire, and guessing are all expressed with **patterns**: a verb stem + an ending + a noun or auxiliary verb.

| Meaning | Pattern | Example |
|---|---|---|
| can | -(으)ㄹ 수 있다 | 갈 수 있어요 |
| can't | -(으)ㄹ 수 없다 / 못 | 갈 수 없어요 |
| know how to | -(으)ㄹ 줄 알다 | 운전할 줄 알아요 |
| must | -아/어야 하다/되다 | 가야 해요 |
| may | -아/어도 되다 | 가도 돼요 |
| must not | -(으)면 안 되다 | 가면 안 돼요 |
| don't have to | 안 -아/어도 되다 | 안 가도 돼요 |
| want to | -고 싶다 | 가고 싶어요 |
| intend to | -(으)려고 하다 | 가려고 해요 |
| probably, seems | -(으)ㄹ 것 같다 | 갈 것 같아요 |

## Ability and possibility

### -(으)ㄹ 수 있다 / 없다

"Can / can't": the literal meaning is "there is / isn't a way to...". It covers ability, permission, and possibility.

- 한국어를 **할 수 있어요**. (I can speak Korean.)
- 내일은 **갈 수 없어요**. (I can't go tomorrow.)
- 누구나 실수**할 수 있어요**. (Anyone can make a mistake.)

Compare with **못** (see [Negation](./16_negation.md)): 못 가요 and 갈 수 없어요 both mean "I can't go". 못 is more everyday.

### -(으)ㄹ 줄 알다 / 모르다

"Know / don't know **how** to" (a learned skill):

- 김치 **만들 줄 알아요**? (Do you know how to make kimchi?)
- 저는 수영**할 줄 몰라요**. (I don't know how to swim.)

## Obligation

### -아/어야 하다 / 되다

"Must, have to". **되다** is more casual than 하다:

- 내일 일찍 일어나**야 해요**. (I have to get up early tomorrow.)
- 약을 먹어**야 돼요**. (I have to take medicine.)
- 이제 가**야겠어요**. (I should get going now.) (**-아/어야겠다**: "I think I'd better")

### -지 않으면 안 되다

A stronger, more formal "must" (literally "if you don't, it's not OK"):

- 서류를 오늘까지 내**지 않으면 안 돼요**. (You must submit the documents by today.)

### Not necessary: 안 -아/어도 되다 / -지 않아도 되다

- 내일은 **안 와도 돼요**. (You don't have to come tomorrow.)
- 걱정하**지 않아도 돼요**. (You don't need to worry.)

## Permission and prohibition

| Meaning | Pattern | Example |
|---|---|---|
| may, it's OK to | -아/어도 되다 / 괜찮다 | 여기 앉아**도 돼요**? (May I sit here?) |
| must not | -(으)면 안 되다 | 여기서 담배를 피우**면 안 돼요**. (You can't smoke here.) |

Asking and answering permission:

- A: 창문 좀 열어**도 돼요**? (May I open the window?)
- B: 네, 열어**도 돼요**. (Yes, go ahead.) / 아니요, 열**면 안 돼요**. (No, you can't.)

The literal meaning is "even if you do it, it's OK" and "if you do it, it's not OK".

## Desire

### -고 싶다 / -고 싶어하다

**-고 싶다** is "want to", for the **speaker** (or the listener, in a question):

- 한국에 가**고 싶어요**. (I want to go to Korea.)
- 뭐 먹**고 싶어요**? (What do you want to eat?)

For a **third person**, use **-고 싶어하다** (see the feelings rule in [Adjectives](./11_adjectives.md)):

- 동생이 강아지를 키우**고 싶어해요**. (My younger sibling wants to raise a puppy.)

With -고 싶다, the object may take 을/를 or 이/가: 물**을** / 물**이** 마시고 싶어요 (I want to drink water).

## Intention and plans

| Pattern | Nuance | Example |
|---|---|---|
| **-(으)려고 하다** | intend to, be about to | 내년에 결혼하**려고 해요**. (I'm planning to get married next year.) |
| **-(으)ㄹ 거예요** | plan (neutral) | 주말에 쉴 **거예요**. (I'm going to rest this weekend.) |
| **-기로 하다** | decide to, agree to | 담배를 끊**기로 했어요**. (I decided to quit smoking.) |
| **-(으)ㄹ게요** | promise to the listener | 내일 전화**할게요**. (I'll call you tomorrow.) |
| **-(으)ㄹ래요** | want to (casual) | 저는 집에 **갈래요**. (I'm going to go home.) |

See [Tenses and aspect](./15_tenses_aspect.md) for more on the future forms.

## Guessing and probability

| Pattern | Nuance | Example |
|---|---|---|
| **-(으)ㄹ 것 같다** | I think it will / probably | 비가 **올 것 같아요**. (It looks like it's going to rain.) |
| **-(으)ㄴ/는 것 같다** | it seems (based on evidence) | 밖에 비가 오**는 것 같아요**. (It seems to be raining outside.) |
| **-겠-** | guess from what you see/hear | 맛있**겠어요**! (That looks delicious!) |
| **-나 보다 / -(으)ㄴ가 보다** | apparently (from evidence) | 민수가 바쁜**가 봐요**. (Minsu must be busy.) |
| **-(으)ㄹ지도 모르다** | might, may | 늦**을지도 몰라요**. (I might be late.) |
| **아마 ... -(으)ㄹ 거예요** | probably | **아마** 집에 있**을 거예요**. (He's probably at home.) |

**-(으)ㄹ 것 같다** is also a very common **softener**, making opinions less direct:

- 이게 더 좋**을 것 같아요**. (I think this one would be better.)
- 잘 모르**겠어요**. (I'm not sure.)

Tense in -것 같다:

| | Verb | Adjective |
|---|---|---|
| past | 간 것 같아요 (seems he went) | 추웠던 것 같아요 (seems it was cold) |
| present | 가는 것 같아요 (seems he's going) | 추운 것 같아요 (seems it's cold) |
| future / guess | 갈 것 같아요 (seems he'll go) | 추울 것 같아요 (it'll probably be cold) |

## Trying, suggesting, advising

| Pattern | Meaning | Example |
|---|---|---|
| **-아/어 보다** | try (doing) | 이 옷 입어 **보세요**. (Try this on.) |
| **-아/어 본 적이 있다** | have done before | 김치를 먹어 **본 적이 있어요**. (I've tried kimchi before.) |
| **-(으)ㄹ까요?** | shall we? / shall I? | 같이 **갈까요**? (Shall we go together?) |
| **-는 게 좋겠다** | had better | 오늘은 쉬**는 게 좋겠어요**. (You'd better rest today.) |
| **-(으)세요** | polite request / advice | 푹 쉬**세요**. (Get some good rest.) |
| **-아/어 주세요** | please do for me | 다시 말해 **주세요**. (Please say it again.) |

A polite request can be softened further: 도와**주시겠어요**? / 도와**주실 수 있어요**? (Could you help me?)
