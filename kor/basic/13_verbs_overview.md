# Verbs Overview (동사)

Korean verbs have a **stem** and take **endings** (see [Verb endings](./06_verb_endings.md)). They don't change for person or number: 가요 is "I go", "you go", "she goes", and "they go".

- 저는 학교에 **가요**. (I go to school.)
- 친구들이 학교에 **가요**. (My friends go to school.)

## 동사 vs 형용사

Verbs (action) and adjectives (state) conjugate almost the same way. The quickest test is the plain present (해라체) and the modifier form:

| Test | 동사 (먹다) | 형용사 (예쁘다) |
|---|---|---|
| Plain present | 먹**는다** | 예쁘**다** |
| Before a noun (now) | 먹**는** 사람 | 예쁜 꽃 |
| Command / "let's" | 먹어라, 먹자 | ✗ |
| -고 있다 | 먹고 있다 | ✗ |

See [Word classes](./03_word_classes.md) and [Adjectives](./11_adjectives.md).

## Special predicates

### 이다 / 아니다 (to be / not to be)

**이다** links a noun to what it is. It attaches to the noun without a space.

| | After a consonant | After a vowel |
|---|---|---|
| 해요체 | 학생**이에요** | 의사**예요** |
| Past | 학생**이었어요** | 의사**였어요** |
| 합쇼체 | 학생**입니다** | 의사**입니다** |

The negative is a separate word, **아니다**, and the noun takes **이/가**:

- 저는 학생**이 아니에요**. (I'm not a student.)
- 이건 제 가방**이 아니에요**. (This isn't my bag.)

### 있다 / 없다 (exist, have)

These cover both "there is / isn't" and "to have / not have":

| Use | Example |
|---|---|
| location: X is at Y | 화장실은 2층**에 있어요**. (The restroom is on the 2nd floor.) |
| existence: there is X | 여기 식당**이 있어요**. (There's a restaurant here.) |
| possession: I have X | 저는 동생**이 있어요**. (I have a younger sibling.) |
| lack | 시간**이 없어요**. (I don't have time.) |

Honorific: **계시다** for a respected person's location, **있으시다** for their possessions (see [Speech levels](./07_speech_levels.md)).

Many adjectives are built on them: 맛있다 / 맛없다 (tasty / not tasty), 재미있다 / 재미없다 (fun / boring), 멋있다 (cool, stylish).

### 하다 verbs

**하다** (to do) is the most common verb, and thousands of verbs are **noun + 하다**:

- 공부하다 (to study), 일하다 (to work), 요리하다 (to cook), 운동하다 (to exercise), 사랑하다 (to love)

These can split with 을/를: 공부**를** 해요 = 공부해요. Splitting lets you modify the noun: 한국어 공부를 해요 (I study Korean).

하다 is irregular: 하 + 여 → **해**: 해요, 했어요, 해서, 해도.

## Transitive and intransitive pairs

Many actions come in pairs: one verb where **someone does it** (takes 을/를), one where **it happens** (takes 이/가):

| Someone does it | It happens |
|---|---|
| 문을 **열다** (open the door) | 문이 **열리다** (the door opens) |
| 문을 **닫다** (close the door) | 문이 **닫히다** (the door closes) |
| 불을 **켜다** (turn on the light) | 불이 **켜지다** (the light comes on) |
| 불을 **끄다** (turn off the light) | 불이 **꺼지다** (the light goes off) |
| 일을 **시작하다** (start the work) | 일이 **시작되다** (the work starts) |
| 공을 **떨어뜨리다** (drop the ball) | 공이 **떨어지다** (the ball falls) |

Korean prefers the "it happens" form when there's no need to name who did it: 문이 열렸어요 (The door opened.) See [Voice](./17_voice.md).

## Auxiliary verbs (보조 용언)

A main verb + ending + a second verb that adds a shade of meaning. These are extremely common.

| Pattern | Meaning | Example |
|---|---|---|
| **-아/어 주다** | do for someone | 도와**주세요**. (Please help me.) |
| **-아/어 드리다** | do for someone (humble) | 제가 도와**드릴게요**. (I'll help you.) |
| **-아/어 보다** | try (doing) | 한번 먹어 **보세요**. (Try eating it.) |
| **-아/어 버리다** | do completely (often regret or relief) | 다 먹어 **버렸어요**. (I ate it all up.) |
| **-아/어 놓다 / 두다** | do in advance, and leave it | 예약해 **놓았어요**. (I've made a reservation.) |
| **-아/어 가다 / 오다** | progress away / toward now | 다 돼 **가요**. (It's almost done.) / 10년 동안 살아 **왔어요**. (I've lived here for 10 years.) |
| **-아/어 있다** | resulting state | 앉아 **있어요**. (She's sitting.) |
| **-고 있다** | ongoing action | 먹고 **있어요**. (I'm eating.) |
| **-고 싶다** | want to | 가고 **싶어요**. (I want to go.) |
| **-게 되다** | end up, come to | 한국에서 살게 **됐어요**. (I ended up living in Korea.) |
| **-지 않다 / 못하다** | not / cannot | 가지 **않아요**. (I don't go.) |

**Trap:** the "help" in Korean is almost always **도와주다** (help-for-you), not bare 돕다: 도와주세요 (Please help me).

## Motion verb compounds

Directional verbs combine with **가다** (go, away from speaker) and **오다** (come, toward speaker):

| Stem | + 가다 | + 오다 |
|---|---|---|
| 들다 (enter) | **들어가다** (go in) | **들어오다** (come in) |
| 나다 (exit) | **나가다** (go out) | **나오다** (come out) |
| 오르다 (rise) | **올라가다** (go up) | **올라오다** (come up) |
| 내리다 (descend) | **내려가다** (go down) | **내려오다** (come down) |
| 돌다 (turn) | **돌아가다** (go back) | **돌아오다** (come back) |
| 가지다 (hold) | **가져가다** (take along) | **가져오다** (bring) |

- 들어**오세요**. (Come in.)
- 우산 **가져가세요**. (Take an umbrella with you.)

## Common verbs

| | | | |
|---|---|---|---|
| 가다 (go) | 오다 (come) | 먹다 (eat) | 마시다 (drink) |
| 보다 (see, watch) | 듣다 (listen) | 말하다 (speak) | 읽다 (read) |
| 쓰다 (write; use) | 사다 (buy) | 팔다 (sell) | 주다 (give) |
| 받다 (receive) | 만나다 (meet) | 자다 (sleep) | 일어나다 (get up) |
| 앉다 (sit) | 서다 (stand) | 알다 (know) | 모르다 (not know) |
| 좋아하다 (like) | 배우다 (learn) | 가르치다 (teach) | 기다리다 (wait) |
| 입다 (wear, clothes) | 타다 (ride) | 살다 (live) | 만들다 (make) |

**Trap:** "to wear" depends on the body part: **입다** (clothes), **신다** (shoes, socks), **쓰다** (hat, glasses), **끼다** (gloves, rings), **차다** (watch), **매다** (tie, belt). Taking off: **벗다** (clothes, shoes, hat), **빼다** (ring), **풀다** (tie, watch).
