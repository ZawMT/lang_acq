# Stacking politeness, honorifics and tense on a verb

A Korean verb is built by adding pieces to the stem **in a fixed order**. Once you know the order, politeness doesn't make modal patterns harder: each piece has its own slot and its own simple rule. (Basics in [Speech levels](../basic/07_speech_levels.md), [Tenses and aspect](../basic/15_tenses_aspect.md) and [Modality](../basic/18_modality.md).)

```
가 + 시 + ㄹ 수 + 있 + 어요
stem  honor  modal   helper  politeness
```

## 1. The slot order

```
stem  →  -(으)시-  →  -았/었-  →  -겠-  →  ending
         honorific    past        will/guess  politeness, question, connective…
```

You don't use every slot every time, but the ones you do use always come in this order.

| Form | Slots | Meaning |
|---|---|---|
| 가요 | 가 + 아요 | goes |
| 갔어요 | 가 + 았 + 어요 | went |
| 가세요 | 가 + 시 + 어요 | (respected person) goes |
| 가셨어요 | 가 + 시 + 었 + 어요 | (respected person) went |
| 가셨겠어요 | 가 + 시 + 었 + 겠 + 어요 | (they) must have gone |
| 가셨습니까? | 가 + 시 + 었 + 습니까 | Did (they) go? (formal) |

Two contractions make these look less regular than they are:

- **시 + 어 → 셔**, so 시 + 었 → **셨**
- **시 + 어요 → 세요**, irregular but very common

## 2. Two sound rules for attaching endings

- **(으):** add 으 after a consonant, but not after a vowel or ㄹ: 갈 수 있다, 먹**을** 수 있다
- **아/어:** use 아 after ㅏ or ㅗ and 어 after any other vowel; 하다 → 해: 가도, 먹**어**도, 해도

## 3. Politeness goes on the last verb only

A modal pattern ends in a helper verb (있다, 없다, 되다, 하다, 모르다, 싶다, 같다). **Only that helper changes for speech level.** The front part stays the same.

| Modal | Casual | Polite (-요) | Formal (-습니다) |
|---|---|---|---|
| can | 갈 수 있어 | 갈 수 있어요 | 갈 수 있습니다 |
| will | 갈 거야 | 갈 거예요 | 갈 겁니다 |
| might | 갈지도 몰라 | 갈지도 몰라요 | 갈지도 모릅니다 |
| may | 가도 돼 | 가도 돼요 | 가도 됩니다 |
| must | 가야 해 | 가야 해요 | 가야 합니다 |
| must not | 가면 안 돼 | 가면 안 돼요 | 가면 안 됩니다 |
| want to | 가고 싶어 | 가고 싶어요 | 가고 싶습니다 |
| seems | 가는 것 같아 | 가는 것 같아요 | 가는 것 같습니다 |

The only wrinkles come from the helper verbs themselves:

- 되다 → 돼 / 돼요
- 모르다 → 몰라 (르 irregular)
- 거예요 ↔ 거야 ↔ 겁니다, because it is a contraction of 것이에요

## 4. Patterns tied to one speech level

Some patterns are **endings**, not helper verbs, so they don't follow the table above:

| Pattern | Casual | Polite | Formal |
|---|---|---|---|
| I'll (promise) | 갈게 | 갈게요 | 가겠습니다 |
| shall we? | 갈까? | 갈까요? | 가시겠습니까? |
| let's | 가자 | 가요 | 갑시다 |

**Trap:** 갑시다 looks formal, but it's awkward toward superiors. Use **가시죠** instead.

## 5. Honorific -시-: respect for the doer

Polite endings (-요, -습니다) show respect to the **listener**. **-(으)시-** shows respect to the **subject**, the person doing the action. It goes on the **main verb**, before the modal part:

- 가**실** 수 있어요? (Can you go?, to a superior)
- 하**셔**야 해요. (You have to do it.)
- 드**셔**도 돼요. (You may eat.) (먹다 → 드시다, a special honorific verb)

**Trap:** don't use -시- about yourself. 제가 가실 수 있어요 is wrong: say 제가 갈 수 있어요.

## 6. Tense: on the helper or on the main verb?

A modal pattern has **two verbs**, and each has its own slots:

```
가 + 시 + ㄹ 수   |   있 + 었 + 어요
main verb             helper verb
```

**Past on the helper:** the ability, need or wish itself was in the past.

| Form | Meaning |
|---|---|
| 갈 수 있**었**어요 | could go / was able to go |
| 가야 **했**어요 | had to go |
| 가고 싶**었**어요 | wanted to go |
| 가**실** 수 있**었**어요 | (respected person) could go |
| 가**셔**야 **했**습니다 | (respected person) had to go (formal) |

**Past on the main verb:** the action is in the past, but you are guessing about it now.

| Form | Meaning |
|---|---|
| 갈지도 몰라요 | might go |
| **갔**을지도 몰라요 | might have gone |
| **갔**을 거예요 | probably went |
| **간** 것 같아요 / **갔던** 것 같아요 | seems to have gone |

## 7. The same slots before connectives

The slots also appear before connective endings, which link clauses instead of ending the sentence (see [Connective endings](../basic/19_connective_endings.md)):

- 가**시**면 (if you go, honorific)
- 가**셨**는데 (they went, but…)
- 가**셨**으니까 (since they went…)

## Rule of thumb

- Read a verb **from the right**: ending → 겠 → 었 → 시 → stem.
- In a modal pattern, **-시-** goes on the main verb. **Politeness** goes on the last verb. **Tense** goes wherever the past actually is.
