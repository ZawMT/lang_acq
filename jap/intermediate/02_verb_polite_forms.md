# Stacking politeness, keigo and tense on a verb

A Japanese verb is built by adding pieces after the stem **in a fixed order**. Once you know the order, politeness doesn't make modal patterns harder: each piece has its own slot and its own simple rule. (Basics in [Verb conjugation](../basic/07_verb_conjugation.md), [Politeness and Keigo](../basic/08_politeness_keigo.md) and [Modality](../basic/18_modality.md).)

```
お使いになる → お使いになれ + ます
keigo verb     + potential     politeness
```

## 1. The slot order

```
verb  →  させる  →  られる  →  たい  →  ない  →  ます  →  た
         causative  passive    want     negative  polite    past
```

You don't use every slot every time, but the ones you do use always come in this order. Read a long verb **from the right** to take it apart.

| Form | Slots | Meaning |
|---|---|---|
| 書（か）く | 書く | writes |
| 書きます | 書き + ます | writes (polite) |
| 書きました | 書き + まし + た | wrote (polite) |
| 書きたくない | 書き + たく + ない | don't want to write |
| 書かせられる | 書か + せ + られる | be made to write |
| 書かせられませんでした | 書か + せ + られ + ません + でした | wasn't made to write (polite) |

**Keigo replaces the verb itself**, in the first slot. Everything else stacks after it as usual:

| Form | Slots | Meaning |
|---|---|---|
| お書きになる | keigo verb | (respected person) writes |
| お書きになりました | お書きになり + まし + た | (they) wrote |
| お書きになれます | お書きになれ + ます | (they) can write |

## 2. ます or です at the end

The polite ending depends on what comes last:

| Last piece | Polite ending | Example |
|---|---|---|
| a verb | **ます** | 行（い）き**ます**, 行けま**す** |
| an い-adjective-type ending (たい, ない, いい) | **です** | 行きたい**です**, 行ってもいい**です** |
| a noun or だ-ending | **です** (だ → です) | 行くつもり**です**, 行くよう**です** |

**Trap:** with い-adjective-type endings, the past goes **before** です: 行きたかった**です** (✗ 行きたいでした).

## 3. Politeness goes on the last piece only

A modal pattern ends in a helper (できる, なる, いい, ない, だろう, よう…). **Only that last piece changes for politeness.** The front part stays the same.

| Modal | Plain | Polite |
|---|---|---|
| can | 行ける | 行けます |
| can (more formal) | 行くことができる | 行くことができます |
| will probably | 行くだろう | 行くでしょう |
| might | 行くかもしれない | 行くかもしれません |
| may | 行ってもいい | 行ってもいいです |
| must | 行かなければならない | 行かなければなりません |
| must not | 行ってはいけない | 行ってはいけません |
| don't have to | 行かなくてもいい | 行かなくてもいいです |
| want to | 行きたい | 行きたいです |
| seems | 行くようだ / 行くみたい | 行くようです / 行くみたいです |
| plan to | 行くつもりだ | 行くつもりです |

The only wrinkles come from the helpers themselves:

- だろう → **でしょう**
- ない → **ません**: かもしれ**ません**, なり**ません**, いけ**ません**
- いい → **よろしい** for extra politeness: 行ってもよろしいですか

## 4. Patterns tied to one politeness level

Some forms are **separate endings**, not a helper plus です/ます, so each level has its own shape:

| Pattern | Plain | Polite |
|---|---|---|
| let's | 行こう | 行きましょう |
| shall I / shall we? | 行こうか | 行きましょうか |
| won't you? (invitation) | 行かない？ | 行きませんか |
| please do | 行って | 行ってください |

## 5. Keigo on the main verb

### Raising the other person (尊敬語)

The respectful verb goes in the main-verb slot, and the modal follows:

- この部屋（へや）は自由（じゆう）に**お使いになれます**。 (You can use this room freely.)
- 先生（せんせい）は明日（あした）**いらっしゃるでしょう**。 (The teacher will probably come tomorrow.)
- 社長（しゃちょう）はもう**お帰（かえ）りになったようです**。 (The president seems to have gone home already.)

**Trap:** don't give **permission** or **orders** to a superior, even in keigo. ✗ 召（め）し上（あ）がってもいいです sounds like you're allowing them. Use a request or offer instead:

| Avoid | Use |
|---|---|
| 〜てもいいです (you may) | どうぞ〜てください / 〜ていただいて結構（けっこう）です |
| 〜なければなりません (you must) | 〜ていただく必要（ひつよう）があります / 〜ていただけますか |

### Lowering yourself (謙譲語)

For your own actions toward a respected person, use the humble verb in the same slot:

- 明日なら**伺（うかが）えます**。 (I can visit tomorrow.)
- 資料（しりょう）を**拝見（はいけん）してもよろしいでしょうか**。 (May I look at the materials?)
- お荷物（にもつ）、**お持（も）ちしましょうか**。 (Shall I carry your bag?)

**Trap:** never use 尊敬語 about yourself: ✗ 私（わたし）が**いらっしゃいます**. Say 私が**参（まい）ります**.

## 6. Tense: on the last piece or on the main verb?

**Past on the last piece:** the ability, need or wish itself was in the past.

| Form | Meaning |
|---|---|
| 行けました | could go / was able to go |
| 行かなければなりませんでした | had to go |
| 行きたかったです | wanted to go |
| お使いになれました | (respected person) could use it |

**Past on the main verb:** the action is in the past, but you are guessing about it now.

| Form | Meaning |
|---|---|
| 行くかもしれません | might go |
| **行った**かもしれません | might have gone |
| **行った**でしょう | probably went |
| **行った**ようです | seems to have gone |
| **お帰りになった**かもしれません | (respected person) might have gone home |

Both can appear together: 行**けた**かもしれません (might have been able to go).

## 7. Inside the sentence

In a polite sentence, only the **final** verb needs ます. Verbs inside the sentence can stay plain:

- 雨（あめ）が**降（ふ）っている**ので、**行きません**。 (It's raining, so I won't go.)
- 雨が**降っています**ので、… (adding ます inside sounds more formal, as in business or announcements)

Keigo, however, stays on **every** verb about the respected person, even inside the sentence:

- 先生が**いらっしゃったら**、教（おし）えてください。 (When the teacher arrives, please let me know.)
- 社長が**おっしゃった**ように、… (As the president said, …)

## Rule of thumb

- Read a verb **from the right**: た → ます → ない → たい → られる → させる → verb.
- **Keigo** replaces the main verb. **Politeness** (ます/です) goes on the last piece. **Tense** goes wherever the past actually is.
