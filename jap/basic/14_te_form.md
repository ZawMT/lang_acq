# The て-form (て形)

The **て-form** is the most-used verb form in Japanese. On its own it means roughly "do and…", and with other words after it, it builds requests, ongoing actions, permission, and much more. The **た-form** (past) is made the same way, with た/だ in place of て/で.

## Making the て-form

### Group 2 and Group 3

| Group | Rule | Examples |
|---|---|---|
| Group 2 | drop る, add **て** | 食（た）べる → 食べ**て**, 見（み）る → 見**て** |
| する | → **して** | 勉強（べんきょう）する → 勉強**して** |
| 来る（くる） | → **きて** | 来**て** |

### Group 1: depends on the last kana

| Ending | て-form | た-form | Examples |
|---|---|---|---|
| **う, つ, る** | → **って** | → **った** | 買（か）う → 買**って**, 待（ま）つ → 待**って**, 帰（かえ）る → 帰**って** |
| **む, ぶ, ぬ** | → **んで** | → **んだ** | 読（よ）む → 読**んで**, 遊（あそ）ぶ → 遊**んで**, 死（し）ぬ → 死**んで** |
| **く** | → **いて** | → **いた** | 書（か）く → 書**いて**, 聞（き）く → 聞**いて** |
| **ぐ** | → **いで** | → **いだ** | 泳（およ）ぐ → 泳**いで**, 急（いそ）ぐ → 急**いで** |
| **す** | → **して** | → **した** | 話（はな）す → 話**して**, 出（だ）す → 出**して** |

**Exception:** **行く（いく）** → 行**って**, 行**った** (not ✗ 行いて).

### Adjectives and nouns

| Type | て-form | Example |
|---|---|---|
| い-adjective | い → **くて** | 安（やす）い → 安**くて** |
| いい | → **よくて** | |
| な-adjective | + **で** | 静（しず）か → 静か**で** |
| noun | + **で** | 学生（がくせい） → 学生**で** |

### Negative て-forms

| Form | Meaning | Example |
|---|---|---|
| 〜**ないで** | without doing; please don't | 朝（あさ）ご飯（はん）を食べ**ないで**来た。 (I came without eating breakfast.) |
| 〜**なくて** | because (it's) not | 分（わ）から**なくて**困（こま）った。 (I didn't understand, so I was stuck.) |

## Uses on its own

### Linking: and, and then

The て-form joins actions in **order**, and links descriptions:

- 朝起きて、シャワーを浴（あ）びて、出かけます。 (I get up, take a shower, and go out.)
- この店（みせ）は安くて、おいしい。 (This restaurant is cheap and good.)
- 兄（あに）は医者（いしゃ）**で**、姉（あね）は先生（せんせい）です。 (My older brother is a doctor, and my older sister is a teacher.)

The **tense** comes from the last verb: 起きて、出かけ**ました** (I got up and went out).

### Means and manner: by doing

- 歩（ある）いて行きます。 (I'll walk there. → go by walking)
- 急いで帰った。 (I hurried home.)

### Reason

- 遅（おく）れて、すみません。 (Sorry for being late.)
- 風邪（かぜ）を引（ひ）いて、休（やす）みました。 (I caught a cold and took the day off.)

### 〜てから: after doing

- 手（て）を洗（あら）って**から**食べてください。 (Please wash your hands before eating. → after washing)

## Patterns built on the て-form

| Pattern | Meaning | Example |
|---|---|---|
| 〜て**ください** | please do | ちょっと待って**ください**。 (Please wait a moment.) |
| 〜て**いる** | is doing; is in a state | 雨（あめ）が降（ふ）って**いる**。 (It's raining.) |
| 〜て**ある** | has been done (on purpose) | 窓（まど）が開（あ）けて**ある**。 (The window has been opened.) |
| 〜て**もいい** | may, it's OK to | 入（はい）って**もいい**ですか。 (May I come in?) |
| 〜て**はいけない** | must not | ここで写真（しゃしん）を撮（と）って**はいけません**。 (You must not take photos here.) |
| 〜て**みる** | try (and see) | 着（き）て**みて**もいいですか。 (May I try it on?) |
| 〜て**おく** | do in advance, leave as is | 予約（よやく）して**おきます**。 (I'll book ahead.) |
| 〜て**しまう** | do completely; do by mistake | 全部（ぜんぶ）食べて**しまった**。 (I ate it all.) |
| 〜て**いく** | go on doing; go and do | 寒くなって**いく** (get colder and colder) |
| 〜て**くる** | come to; go and come back | 雨が降って**きた**。 (It's started raining.) |
| 〜て**あげる / くれる / もらう** | do for someone | 手伝（てつだ）って**くれた**。 (They helped me.) |
| 〜て**ほしい** | want someone to do | 来て**ほしい**。 (I want you to come.) |
| 〜て**も** | even if | 雨が降って**も**行きます。 (I'll go even if it rains.) |

See [Tense and Aspect](./15_tense_aspect.md) for 〜ている and 〜てある, [Giving and Receiving](./22_giving_receiving.md) for 〜てあげる etc., and [Modality](./18_modality.md) for permission and prohibition.

### 〜てしまう: completion and regret

〜てしまう has two meanings, often together:

1. **Finished completely**: 宿題（しゅくだい）をやって**しまった**。 (I've finished my homework.)
2. **Something unfortunate or unintended**: 財布（さいふ）をなくして**しまった**。 (I've gone and lost my wallet.)

### 〜ておく: getting ready

**〜ておく** means doing something now **for later**, or leaving something in a state:

- 旅行（りょこう）の前に、地図（ちず）を見て**おく**。 (Look at the map before the trip.)
- 窓は開けて**おいて**ください。 (Please leave the window open.)

### Requests

| Form | Politeness |
|---|---|
| 〜て。 | casual: 見て！ (Look!) |
| 〜てください。 | polite |
| 〜てくれる？ | casual request |
| 〜てくれませんか。 | polite request |
| 〜ていただけませんか。 | very polite request |

**Trap:** 〜てください is polite in form, but it's still a request or instruction. To a superior, the softer 〜ていただけませんか is better.

## Casual contractions

In speech, these て-form combinations shorten:

| Full | Contracted | Example |
|---|---|---|
| 〜ている | 〜**てる** | 何（なに）して**る**の？ (What are you doing?) |
| 〜ておく | 〜**とく** | 買っ**とく**ね。 (I'll buy it in advance.) |
| 〜てしまう | 〜**ちゃう** | 食べ**ちゃった**。 (I ate it all / Oops, I ate it.) |
| 〜でしまう | 〜**じゃう** | 飲ん**じゃった**。 (I drank it all.) |
| 〜てはいけない | 〜**ちゃだめ** | 触（さわ）っ**ちゃだめ**。 (Don't touch.) |
| 〜ではいけない | 〜**じゃだめ** | 飲ん**じゃだめ**。 (Don't drink it.) |
