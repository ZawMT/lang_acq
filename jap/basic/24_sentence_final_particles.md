# Sentence-final Particles and Interjections (終助詞と感動詞)

**Sentence-final particles** (終助詞（しゅうじょし）) come at the very **end** of a sentence and show the speaker's **attitude**: asking, checking, telling, wondering. They carry a lot of the feeling in spoken Japanese.

**Interjections** (感動詞（かんどうし）) stand on their own: ああ, えっ, はい, ねえ.

## Sentence-final particles

| Particle | Function | Example |
|---|---|---|
| **か** | question | 行きます**か**。 (Are you going?) |
| **ね** | seeking agreement, shared feeling | いい天気（てんき）です**ね**。 (Nice weather, isn't it?) |
| **よ** | telling the listener something new | この店（みせ）、おいしい**よ**。 (This place is good, you know.) |
| **よね** | checking something you think is shared | 明日（あした）休みだ**よね**？ (Tomorrow's a day off, right?) |
| **な / なあ** | talking to yourself, feeling | きれいだ**なあ**。 (How beautiful.) |
| **かな** | I wonder | 雨（あめ）、降（ふ）る**かな**。 (I wonder if it'll rain.) |
| **の** | explanation; casual question | どこ行く**の**？ (Where are you going?) |
| **っけ** | trying to remember | 会議（かいぎ）、何時（なんじ）だった**っけ**？ (What time was the meeting again?) |
| **ぞ / ぜ** | strong assertion (rough, masculine) | 行く**ぞ**！ (Let's go!) |
| **わ** | soft emphasis (feminine in Tokyo; neutral in Kansai) | 私（わたし）も行く**わ**。 (I'll go too.) |
| **さ** | casual, matter-of-fact | まあ、いい**さ**。 (Oh well, it's fine.) |
| **もん** | because (excuse, childish) | だって、眠（ねむ）い**もん**。 (Well, I'm sleepy!) |

### ね: let's share this

**ね** invites the listener to **agree** or shows you **share** their feeling:

- 寒（さむ）いです**ね**。 (It's cold, isn't it?)
- A: 試験（しけん）、合格（ごうかく）しました！ B: よかったです**ね**！ (A: I passed the exam! B: That's great!)
- じゃあ、3時に**ね**。 (OK, at 3 then.) → confirming

It's used constantly and makes speech sound friendly. A stretched **ねえ** adds feeling: 大変（たいへん）だった**ねえ**。 (That must have been hard.)

### よ: here's something you didn't know

**よ** marks information the **speaker** knows and the **listener** doesn't, or a firm opinion:

- 電車（でんしゃ）、もう来ました**よ**。 (The train's already here.)
- 大丈夫（だいじょうぶ）です**よ**。 (It's fine, really.)
- 早く行こう**よ**。 (Come on, let's go.) → urging

**Trap:** **よ** can sound pushy or like correcting someone, especially to superiors. Use it for helpful information, not for things the listener obviously knows.

### よね: we both know this, right?

**よね** = you think the listener knows it too, and you're checking:

- 田中（たなか）さんって、大阪（おおさか）出身（しゅっしん）です**よね**？ (Tanaka's from Osaka, right?)

### ね vs よ

| ね | よ |
|---|---|
| the listener knows too | the listener doesn't know |
| きれいです**ね**。 (It's pretty, isn't it?) — both looking at it | きれいです**よ**。 (It's pretty, I'm telling you.) — recommending a place |

## Gendered speech

Some particles have a traditional **gender** feel. In real life, modern speech is much less gendered than in anime, drama, and translated fiction.

| Feel | Particles | Notes |
|---|---|---|
| traditionally feminine | **わ** (rising), **かしら** (I wonder), **のよ**, **わね** | now often sounds old-fashioned or "fictional" |
| traditionally masculine | **ぞ**, **ぜ**, **な** (command), **だろ** | rough; fine among friends, not polite |
| neutral | **ね**, **よ**, **よね**, **かな**, **の?** | safe for anyone |

**Trap:** learners who pick up Japanese from anime can sound unnaturally rough (ぞ, ぜ, お前). Stick to the neutral particles.

## Casual questions

| Form | Feel |
|---|---|
| 行く？ (rising tone) | neutral casual |
| 行く**の**？ | soft, asking for an explanation |
| 行く**か**？ | rough, or an invitation (行く**か**！ = Let's go!) |
| 行く**かい**？ | friendly, slightly old-fashioned |
| 行く**の**か？ | surprised |

## Interjections (感動詞)

### Emotion

| Word | Feeling | Example |
|---|---|---|
| **あ / ああ** | realization | **あ**、忘（わす）れた！ (Oh, I forgot!) |
| **えっ / ええっ** | surprise, disbelief | **えっ**、本当（ほんとう）？ (What, really?) |
| **わあ / うわあ** | wonder, amazement | **わあ**、きれい！ (Wow, beautiful!) |
| **うわっ** | shock, disgust | **うわっ**、虫（むし）だ！ (Ugh, a bug!) |
| **おお** | admiration | **おお**、すごい！ (Oh, amazing!) |
| **あれ?** | puzzled | **あれ**？鍵（かぎ）がない。 (Huh? My key's not here.) |
| **おや** | mild surprise (older) | |
| **まあ** | surprise (traditionally feminine) | **まあ**、かわいい！ (Oh my, how cute!) |
| **しまった** | oops, damn | **しまった**！財布（さいふ）を忘れた。 (Oh no! I forgot my wallet.) |
| **やった** | yes!, I did it | **やった**！合格した！ (Yes! I passed!) |
| **よかった** | phew, I'm glad | |
| **痛（いた）っ** | ouch | |
| **ほら** | look, see? | **ほら**、言ったでしょう。 (See, I told you.) |
| **さあ** | well, come on; I don't know | **さあ**、行こう。 (Come on, let's go.) / **さあ**…分かりません。 (Hmm… I don't know.) |
| **やばい** | (slang) terrible; awesome | |

### Answering

| Word | Level | Meaning |
|---|---|---|
| **はい** | polite | yes; I'm listening; here (roll call) |
| **ええ** | polite, softer | yes |
| **うん** | casual | yeah |
| **いいえ** | polite | no |
| **いえ** | polite, softer | no, not at all |
| **いや** | casual | no |
| **ううん** | casual | nah (falling-rising pitch) |

**Trap:** **うん** (yes) and **ううん** (no) differ only in pitch and length. うん is short and falls; ううん goes down then up.

**いいえ** is also used to deflect thanks or compliments: A: ありがとうございました。 B: **いいえ**。 (Not at all.)

### Calling and getting attention

| Word | Use |
|---|---|
| **すみません** | Excuse me (to a stranger, waiter) |
| **あの / あのう** | Um, excuse me (polite opener) |
| **ねえ** | Hey (casual, to friends) |
| **おい** | Hey! (rough, mostly men) |
| **もしもし** | Hello (on the phone) |

### Fillers (つなぎ言葉)

Fillers give you time to think. Using them sounds natural:

| Filler | Use |
|---|---|
| **えーと / えっと** | um, let me see |
| **あのう** | um (hesitant, polite) |
| **そうですね** | well, let me think |
| **まあ** | well (softening) |
| **なんか** | like, kind of (casual) |
| **ちょっと** | (softens a refusal) ちょっと…, "it's a bit…" |

For listener responses while someone else is talking, see [Aizuchi](./25_aizuchi.md).
