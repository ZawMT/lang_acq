# Adjectives: い and な (形容詞と形容動詞)

Japanese has **two types of adjectives**. Both describe qualities, and both can go before a noun or end a sentence, but they conjugate differently:

| | **い-adjectives** (形容詞（けいようし）) | **な-adjectives** (形容動詞（けいようどうし）) |
|---|---|---|
| Ends in | **い** | (a noun-like stem) |
| Before a noun | 高（たか）**い**山（やま） | 静（しず）か**な**町（まち） |
| As predicate | 高い / 高**いです** | 静か**だ** / 静か**です** |
| Conjugates like | itself (like a verb) | a noun + だ |

## い-adjectives

The final **い** changes:

| Form | Plain | Polite |
|---|---|---|
| Present | 高**い** | 高**いです** |
| Negative | 高**くない** | 高**くないです** / 高**くありません** |
| Past | 高**かった** | 高**かったです** |
| Past negative | 高**くなかった** | 高**くなかったです** / 高**くありませんでした** |
| て-form | 高**くて** | |
| Adverb | 高**く** | |
| ば (if) | 高**ければ** | |

- この本（ほん）は**おもしろかった**です。 (This book was interesting.)
- 今日（きょう）は**寒（さむ）くない**です。 (It's not cold today.)
- 安（やす）**くて**おいしい店（みせ） (a cheap and tasty restaurant)

**Trap:** don't add でした to an い-adjective: ✗ 高いでした → **高かったです**. The past is in the adjective itself.

### いい: the irregular one

**いい** (good) conjugates from its older form **よい**:

| Present | Negative | Past | Past negative | て-form |
|---|---|---|---|---|
| **いい** | **よくない** | **よかった** | **よくなかった** | **よくて** |

The same goes for compounds: かっこいい → かっこ**よかった**, 頭（あたま）がいい → 頭が**よくない**.

## な-adjectives

They work like **nouns**. The stem takes **だ / です**, and takes **な** before a noun:

| Form | Plain | Polite |
|---|---|---|
| Present | 静か**だ** | 静か**です** |
| Negative | 静か**じゃない** / 静か**ではない** | 静か**じゃないです** / 静か**ではありません** |
| Past | 静か**だった** | 静か**でした** |
| Past negative | 静か**じゃなかった** | 静か**じゃなかったです** / 静か**ではありませんでした** |
| て-form | 静か**で** | |
| Before a noun | 静か**な**部屋 | |
| Adverb | 静か**に** | |

- 彼女（かのじょ）は**元気（げんき）です**。 (She's well.)
- この町は**静かじゃない**。 (This town isn't quiet.)
- **きれいな**花（はな） (a pretty flower)

**じゃ** is the spoken form of **では**. Use では in writing and formal speech.

**Trap:** some な-adjectives end in い. They're still な-adjectives:

| Word | Reading | Meaning | Before a noun |
|---|---|---|---|
| **きれい** | きれい | pretty, clean | きれい**な**部屋 |
| **嫌い** | きらい | dislike | 嫌い**な**食べ物（たべもの） |
| **有名** | ゆうめい | famous | 有名**な**人 |
| **丁寧** | ていねい | polite, careful | 丁寧**な**説明（せつめい） |

Their negatives use じゃない: きれい**じゃない** (✗ きれくない).

### Common な-adjectives

好（す）き (liked), 嫌い, 上手（じょうず） (skilled), 下手（へた） (unskilled), 元気 (healthy, lively), 静か (quiet), にぎやか (lively), 便利（べんり） (convenient), 不便（ふべん） (inconvenient), 大切（たいせつ） (important), 大丈夫（だいじょうぶ） (all right), 簡単（かんたん） (easy), 大変（たいへん） (tough), 親切（しんせつ） (kind), 暇（ひま） (free, not busy), 有名 (famous), 心配（しんぱい） (worried)

## Adjectives before nouns

Both types go **directly before** the noun, in any tense:

- **高かった**かばん (the bag that was expensive)
- **静かじゃない**部屋 (a room that isn't quiet)

**大きな / 小さな**: besides 大きい / 小さい, there are 大きな and 小さな, which only go before nouns: 大きな家 = 大きい家 (a big house). They're 連体詞 (see [Word Classes](./04_word_classes.md)).

## Linking adjectives: 〜くて and 〜で

To say "A and B", use the **て-form** of the first adjective:

- この部屋は**広（ひろ）くて**明（あか）るい。 (This room is spacious and bright.)
- 駅（えき）は**便利で**、安い。 (The station is convenient and cheap.)

## Adverbs from adjectives

| Type | Change | Example |
|---|---|---|
| い-adj | い → **く** | 早（はや）い → 早**く**起きる (get up early) |
| な-adj | + **に** | 静か → 静か**に**話す (speak quietly) |

## Becoming: 〜くなる and 〜になる

**なる** (become) shows change:

- 暖（あたた）か**く**なりました。 (It's gotten warmer.)
- 日本語が上手**に**なりました。 (My Japanese has gotten better.)

With **する** (make): 部屋をきれい**に**する (clean the room), 音（おと）を小さ**く**する (turn the volume down).

## Likes, skills, wants: が

好き, 嫌い, 上手, 下手, ほしい mark the object of the feeling with **が**:

- 私（わたし）は猫（ねこ）**が**好きです。 (I like cats.)
- 母（はは）は料理（りょうり）**が**上手です。 (My mother is good at cooking.)
- 新しい車（くるま）**が**ほしい。 (I want a new car.)

**Trap:** **上手** is praise for others. Saying it about yourself sounds boastful; use **得意（とくい）** (my strong point) instead: 料理が得意です.

## Feelings: only for yourself

Adjectives of **feeling or sensation** (うれしい happy, 悲（かな）しい sad, 痛（いた）い painful, ほしい want, 寂（さび）しい lonely) state **your own** feelings. For others, you can't directly know them, so add something:

| For me | For someone else |
|---|---|
| うれしい。 (I'm happy.) | うれし**そう**だ。 (She looks happy.) |
| | うれし**がって**いる。 (He's acting happy.) |
| | うれしい**らしい**。 / うれしい**と言（い）っていた**。 (I hear she's happy.) |

## Comparing

| Pattern | Meaning | Example |
|---|---|---|
| A は B **より** adj | A is more adj than B | 東京（とうきょう）は大阪（おおさか）**より**大きい。 (Tokyo is bigger than Osaka.) |
| A と B と**どちらが** adj ですか | which is more adj? | 犬（いぬ）と猫と**どちらが**好きですか。 (Which do you like better, dogs or cats?) |
| B **より** A **のほうが** adj | A is more adj (than B) | 猫**のほうが**好きです。 (I like cats better.) |
| A は B **ほど** adj + negative | A is not as adj as B | 大阪は東京**ほど**大きくない。 (Osaka isn't as big as Tokyo.) |
| X の中（なか）で **一番（いちばん）** adj | the most adj | 果物（くだもの）の中で**一番**好きなのは… (My favorite fruit is…) |

## Other useful patterns

| Pattern | Meaning | Example |
|---|---|---|
| stem + **すぎる** | too | 高**すぎる** (too expensive), 静か**すぎる** |
| stem + **そう** | looks | おいし**そう** (looks tasty), 元気**そう** |
| い → **さ** | -ness (noun) | 高**さ** (height), 大切**さ** (importance) |

**Trap:** いい → **よさそう** (looks good) and ない → **なさそう** (seems not to be).
