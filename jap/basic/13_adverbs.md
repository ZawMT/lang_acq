# Adverbs (副詞)

Adverbs describe **how, how much, how often, or when**. They never change form, and they usually come **before** the verb or adjective they modify:

- **ゆっくり**話（はな）してください。 (Please speak slowly.)
- **とても**おいしい。 (It's very tasty.)

## Adverbs from adjectives

| Type | Change | Examples |
|---|---|---|
| い-adjective | い → **く** | 早（はや）い → 早**く** (early, quickly), よい → よ**く** (well, often) |
| な-adjective | + **に** | 静（しず）か → 静か**に** (quietly), 上手（じょうず） → 上手**に** (skillfully) |

See [Adjectives](./12_adjectives.md#adverbs-from-adjectives).

## Degree: how much

| Word | Meaning | Notes |
|---|---|---|
| **とても** | very | neutral, polite |
| **すごく** | really, super | casual |
| **大変（たいへん）** | very, extremely | formal |
| **かなり** | quite, fairly | |
| **結構（けっこう）** | pretty, surprisingly | "more than expected" |
| **ちょっと** / **少（すこ）し** | a little | ちょっと is casual |
| **もっと** | more | もっと食べたい (I want to eat more) |
| **ずっと** | much more; all along | ずっと安い (much cheaper) |
| **一番（いちばん）** | the most | 一番好き (like best) |
| **もう少し** | a little more | |
| **ほとんど** | almost (all); hardly (with negative) | |

### With negatives only

Some degree adverbs need a **negative** predicate:

| Word | Meaning | Example |
|---|---|---|
| **あまり** | not very | **あまり**高**くない**。 (It's not very expensive.) |
| **全然（ぜんぜん）** | not at all | **全然**分から**ない**。 (I don't understand at all.) |
| **ちっとも** / **少しも** | not even a little | **少しも**疲（つか）れて**いない**。 (I'm not tired at all.) |
| **決（けっ）して** | never (strong) | **決して**忘（わす）れ**ません**。 (I'll never forget.) |

**Trap:** ✗ あまり高いです. With あまり, the predicate must be negative. In casual speech, 全然 is also used with positives to mean "totally": 全然大丈夫 (totally fine), but this is informal.

## Frequency: how often

From most to least often:

| Word | Meaning |
|---|---|
| **いつも** | always |
| **よく** | often |
| **たいてい** | usually |
| **時々（ときどき）** | sometimes |
| **たまに** | once in a while |
| **あまり** + negative | not often |
| **めったに** + negative | rarely |
| **全然** / **一度（いちど）も** + negative | never |

- **よく**映画（えいが）を見（み）ます。 (I often watch movies.)
- **めったに**料理（りょうり）し**ません**。 (I rarely cook.)

## Time

| Word | Meaning | Example |
|---|---|---|
| **もう** | already; (with negative) no longer | **もう**食べました。 (I've already eaten.) |
| **まだ** | still; (with negative) not yet | **まだ**食べていません。 (I haven't eaten yet.) |
| **すぐ（に）** | right away | **すぐ**行きます。 (I'll go right away.) |
| **今（いま）** | now | |
| **さっき** | a moment ago | |
| **後（あと）で** | later | |
| **もうすぐ** | soon | **もうすぐ**夏（なつ）です。 (It'll be summer soon.) |
| **そろそろ** | about time to | **そろそろ**帰ります。 (I should be heading home.) |
| **先（さき）に** | first, ahead | **先に**行ってください。 (Please go ahead.) |
| **やっと** | finally (after effort) | **やっと**終わった。 (It's finally over.) |
| **ついに** | at last | |
| **まず** | first of all | |
| **ずっと** | the whole time | **ずっと**待っていた。 (I waited the whole time.) |

**Trap: もう and まだ**

| Question | Yes | Not yet |
|---|---|---|
| **もう**食べましたか。 (Have you eaten yet?) | はい、**もう**食べました。 | いいえ、**まだ**です。 / **まだ**食べていません。 |

✗ まだ食べませんでした. "Not yet" uses **〜ていません** (see [Tense and Aspect](./15_tense_aspect.md)).

## Adverbs that set the ending (陳述副詞)

Some adverbs **predict how the sentence will end**. Hearing them tells you what's coming:

| Adverb | Ending it expects | Example |
|---|---|---|
| **たぶん** | 〜でしょう / 〜と思う | **たぶん**雨が降（ふ）る**でしょう**。 (It'll probably rain.) |
| **きっと** | 〜だろう / 〜と思う (strong belief) | **きっと**大丈夫（だいじょうぶ）**だよ**。 (I'm sure it'll be fine.) |
| **もしかしたら** | 〜かもしれない | **もしかしたら**遅（おく）れる**かもしれない**。 (I might be late.) |
| **ぜひ** | 〜たい / 〜てください | **ぜひ**来**てください**。 (Please do come.) |
| **どうぞ** | 〜てください | **どうぞ**座（すわ）っ**てください**。 (Please have a seat.) |
| **もし** | 〜たら / 〜ば | **もし**雨が降っ**たら**… (If it rains…) |
| **まるで** | 〜ようだ / 〜みたい | **まるで**夢（ゆめ）の**ようだ**。 (It's just like a dream.) |
| **なぜ / どうして** | 〜のですか / 〜の? | **どうして**来なかった**の**？ (Why didn't you come?) |
| **必（かなら）ず** | positive (must) | **必ず**連絡（れんらく）します。 (I'll definitely contact you.) |
| **全然, あまり, 決して** | negative | (above) |

## Onomatopoeia (オノマトペ)

Japanese has thousands of sound-symbolic words, and they're used constantly in everyday speech, not just in children's language. There are two main kinds:

- **擬音語（ぎおんご）**: imitate **sounds**: ワンワン (woof), ドンドン (bang bang), ザーザー (pouring rain)
- **擬態語（ぎたいご）**: describe **states, movements, and feelings** that make no sound: キラキラ (sparkling), ドキドキ (heart pounding), ニコニコ (smiling)

Many are **doubled** (ABAB) or end in **り** or **っと**. They're written in hiragana or katakana.

| Word | Meaning | Example |
|---|---|---|
| **ゆっくり** | slowly, leisurely | **ゆっくり**休んでください。 (Take a good rest.) |
| **はっきり** | clearly | **はっきり**言（い）ってください。 (Please say it clearly.) |
| **すっかり** | completely | **すっかり**忘れていた。 (I completely forgot.) |
| **ぐっすり** | (sleep) soundly | **ぐっすり**寝（ね）た。 (I slept like a log.) |
| **ぺらぺら** | fluently | 英語（えいご）が**ぺらぺら**だ。 (He's fluent in English.) |
| **ぺこぺこ** | starving; bowing repeatedly | お腹（なか）が**ぺこぺこ**だ。 (I'm starving.) |
| **にこにこ** | smiling | **にこにこ**笑（わら）う |
| **わくわく** | excited | **わくわく**する |
| **どきどき** | nervous, heart pounding | **どきどき**する |
| **いらいら** | irritated | **いらいら**する |
| **のんびり** | relaxed | **のんびり**過（す）ごす (take it easy) |
| **きらきら** | sparkling | 星（ほし）が**きらきら**光（ひか）る |
| **ざあざあ** | pouring (rain) | 雨が**ざあざあ**降っている |
| **しとしと** | drizzling quietly | |
| **ちゃんと** | properly | **ちゃんと**食べなさい。 (Eat properly.) |
| **そっと** | gently, quietly | |

They're used in several ways:

| Pattern | Example |
|---|---|
| + **と** or alone (adverb) | **ゆっくり(と)**歩く |
| + **する** (verb) | **わくわくする** (be excited), **すっきりする** (feel refreshed) |
| + **だ / です** (predicate) | お腹が**ぺこぺこだ** |
| + **の** (before a noun) | **ふわふわの**パン (fluffy bread) |

## Where adverbs go

Adverbs normally go right **before the word they modify**, but adverbs about the whole sentence (time, frequency, たぶん) often come near the beginning:

- 私（わたし）は**時々**図書館（としょかん）で勉強（べんきょう）します。 (I sometimes study at the library.)
- **たぶん**彼（かれ）は来ないでしょう。 (He probably won't come.)
