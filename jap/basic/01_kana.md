# Kana: Hiragana and Katakana (仮名)

Japanese is written with **three scripts at once**:

| Script | Used for | Example |
|---|---|---|
| **ひらがな (hiragana)** | grammar endings, particles, native words without kanji | た**べる**、わたし**は** |
| **カタカナ (katakana)** | foreign loanwords, foreign names, sound effects, emphasis | **コーヒー**、**アメリカ** |
| **漢字 (kanji)** | the meaning-carrying part of most words | **食**べる、**学生** |

A normal sentence mixes all three: **私**は**コーヒー**を**飲**みます。 (I drink coffee.) See [Kanji and Readings](./02_kanji.md) for kanji.

Both kana are **syllabaries**: each letter is one syllable (more exactly, one beat or *mora*; see [Pronunciation](./03_pronunciation.md#mora-the-beat)). Each set has **46 basic letters**. Both developed from kanji around the 9th century: hiragana from fast, cursive kanji (安 → あ), katakana from pieces of kanji (阿 → ア).

Japanese is written **without spaces**. The switch between kanji, hiragana, and katakana is what shows you where words start. It can be written **horizontally** (left to right) or **vertically** (top to bottom, columns right to left), as in novels and newspapers.

## Hiragana (ひらがな)

### The basic table (五十音, "the fifty sounds")

Read each row left to right: a, i, u, e, o. The order of this table is the Japanese "alphabetical order", used in dictionaries.

| | a | i | u | e | o |
|---|---|---|---|---|---|
| – | あ a | い i | う u | え e | お o |
| k | か ka | き ki | く ku | け ke | こ ko |
| s | さ sa | し **shi** | す su | せ se | そ so |
| t | た ta | ち **chi** | つ **tsu** | て te | と to |
| n | な na | に ni | ぬ nu | ね ne | の no |
| h | は ha | ひ hi | ふ **fu** | へ he | ほ ho |
| m | ま ma | み mi | む mu | め me | も mo |
| y | や ya | | ゆ yu | | よ yo |
| r | ら ra | り ri | る ru | れ re | ろ ro |
| w | わ wa | | | | を **o** |
| | ん **n** | | | | |

The irregular romanizations (shi, chi, tsu, fu) show that those sounds don't follow the row's consonant exactly.

### Voiced sounds: ゛ and ゜

Two small marks at the top right change the consonant:

- **濁点 (dakuten, ゛)** makes it voiced: か ka → が ga.
- **半濁点 (handakuten, ゜)** turns the h-row into p: は ha → ぱ pa.

| | a | i | u | e | o |
|---|---|---|---|---|---|
| g | が ga | ぎ gi | ぐ gu | げ ge | ご go |
| z | ざ za | じ **ji** | ず zu | ぜ ze | ぞ zo |
| d | だ da | ぢ **ji** | づ **zu** | で de | ど do |
| b | ば ba | び bi | ぶ bu | べ be | ぼ bo |
| p | ぱ pa | ぴ pi | ぷ pu | ぺ pe | ぽ po |

**Trap:** **ぢ** and **づ** sound the same as **じ** and **ず**. Almost always write じ and ず. ぢ/づ appear only in a few words where a ち/つ becomes voiced: はな + ち → はな**ぢ** (nosebleed), つ + つく → つ**づ**く (to continue).

### Combined sounds (拗音): small ゃ ゅ ょ

An i-column letter + a **small** ゃ, ゅ, or ょ makes a single beat:

| | ya | yu | yo |
|---|---|---|---|
| k | きゃ kya | きゅ kyu | きょ kyo |
| s | しゃ sha | しゅ shu | しょ sho |
| t | ちゃ cha | ちゅ chu | ちょ cho |
| n | にゃ nya | にゅ nyu | にょ nyo |
| h | ひゃ hya | ひゅ hyu | ひょ hyo |
| m | みゃ mya | みゅ myu | みょ myo |
| r | りゃ rya | りゅ ryu | りょ ryo |
| g | ぎゃ gya | ぎゅ gyu | ぎょ gyo |
| j | じゃ ja | じゅ ju | じょ jo |
| b | びゃ bya | びゅ byu | びょ byo |
| p | ぴゃ pya | ぴゅ pyu | ぴょ pyo |

**Trap:** the size matters. **きよ** (ki-yo, two beats) is not **きょ** (kyo, one beat): びよういん (beauty salon) vs びょういん (hospital).

### Small っ: double consonant

A **small っ** doesn't have its own sound. It means "pause for one beat, then say the next consonant hard". In romaji the next consonant is doubled:

- きって kitte (stamp) vs きて kite (come)
- ざっし zasshi (magazine)
- いっぱい ippai (full)

### Long vowels

In hiragana, a long vowel is written by **adding a vowel letter**:

| Long vowel | Usually written | Example |
|---|---|---|
| aa | + あ | おか**あ**さん (mother) |
| ii | + い | おに**い**さん (older brother) |
| uu | + う | す**う**がく (math) |
| ee | + **い** (mostly), + え (a few words) | せん**せい** (teacher), お**ねえ**さん (older sister) |
| oo | + **う** (mostly), + お (a few words) | **こう**こう (high school), **おお**きい (big) |

### Three particles with special spelling

Three particles keep an old spelling:

| Particle | Written | Said |
|---|---|---|
| topic | **は** | wa |
| direction | **へ** | e |
| object | **を** | o |

- わたし**は** がっこう**へ** いきます。 (I go to school.) → *watashi wa gakkō e ikimasu*
- みず**を** のみます。 (I drink water.) → *mizu o nomimasu*

を is used **only** as the object particle.

## Katakana (カタカナ)

Katakana has exactly the same sounds as hiragana, just different shapes. Katakana is more angular.

| | a | i | u | e | o |
|---|---|---|---|---|---|
| – | ア a | イ i | ウ u | エ e | オ o |
| k | カ ka | キ ki | ク ku | ケ ke | コ ko |
| s | サ sa | シ shi | ス su | セ se | ソ so |
| t | タ ta | チ chi | ツ tsu | テ te | ト to |
| n | ナ na | ニ ni | ヌ nu | ネ ne | ノ no |
| h | ハ ha | ヒ hi | フ fu | ヘ he | ホ ho |
| m | マ ma | ミ mi | ム mu | メ me | モ mo |
| y | ヤ ya | | ユ yu | | ヨ yo |
| r | ラ ra | リ ri | ル ru | レ re | ロ ro |
| w | ワ wa | | | | ヲ o |
| | ン n | | | | |

゛, ゜, small ャ ュ ョ, and small ッ work exactly as in hiragana: ガ, パ, キャ, ベッド (bed).

### The long-vowel bar ー

In katakana, long vowels use the bar **ー** instead of an extra vowel letter. In vertical writing it turns vertical (｜).

- コーヒー (coffee), ケーキ (cake), スーパー (supermarket), ノート (notebook)

### Extra combinations for loanwords

To write foreign sounds, katakana uses combinations that don't exist in hiragana, with a **small vowel**:

| Combination | Sound | Example |
|---|---|---|
| ファ フィ フェ フォ | fa fi fe fo | **ファ**ン (fan), **フォ**ーク (fork) |
| ティ ディ | ti di | パー**ティ**ー (party), **ディ**ズニー |
| トゥ ドゥ | tu du | **トゥ**ルー |
| ウィ ウェ ウォ | wi we wo | **ウィ**ンドウ (window), **ウェ**ブ (web) |
| シェ ジェ チェ | she je che | **シェ**フ (chef), **チェ**ック (check) |
| ヴァ ヴィ ヴ | va vi vu | **ヴァ**イオリン (also written バイオリン) |

### When to use katakana

- **Loanwords (外来語)**: テレビ (TV), パン (bread), アルバイト (part-time job)
- **Foreign names and places**: アメリカ, ロンドン, マイク
- **Sound effects and onomatopoeia**: ドキドキ, ワンワン (see [Adverbs](./13_adverbs.md))
- **Animal and plant names** in science and on signs: ネコ, サクラ
- **Emphasis**, the way italics are used: ダメ!, ヤバい

## Look-alike letters

| Pair | Tell them apart |
|---|---|
| **シ** shi / **ツ** tsu | シ: short strokes lie flatter, long stroke goes **up** from the bottom left. ツ: short strokes stand upright, long stroke goes **down** from the top right. |
| **ソ** so / **ン** n | Same rule: ソ's strokes are upright; ン's long stroke sweeps up from the bottom. |
| **さ** sa / **ち** chi | mirror images |
| **ぬ** nu / **め** me | ぬ has a loop at the end |
| **わ** wa / **れ** re / **ね** ne | the ending: curve in (わ), kick out (れ), loop (ね) |
| **る** ru / **ろ** ro | る has a loop |
| **は** ha / **ほ** ho | ほ has a top bar |
| **ク** ku / **ケ** ke / **タ** ta | count the strokes: 2, 3, 3 |
| **ノ** no / **メ** me | ノ is one stroke; メ crosses it |

## Punctuation

| Mark | Name | Use |
|---|---|---|
| 。 | 句点 (くてん) | full stop |
| 、 | 読点 (とうてん) | comma |
| 「 」 | かぎかっこ | quotation marks (see [Reported Speech](./23_reported_speech.md)) |
| 『 』 | double brackets | titles, quotes inside quotes |
| ・ | なかぐろ | separates foreign names: マイク・スミス |
| 〜 | wave dash | ranges (3〜5), a drawn-out sound |

Question marks and exclamation marks (？！) are common in casual writing but not used in formal writing. There, the question particle か is enough.
